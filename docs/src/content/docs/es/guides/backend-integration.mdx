React PDF Level Up no es solo para el frontend. Puedes utilizar la función `generatePDF` en entornos de Node.js para generar documentos programáticamente, guardarlos en disco o enviarlos como respuesta HTTP.

## Requisitos

Asegúrate de que tu entorno soporte React. Generalmente esto funciona out-of-the-box en frameworks como **Next.js**, **Remix**, **express**, **fastify**, o en scripts simples de Node, bun o cualquier entorno que soporte ES Modules.

## Ejemplo de Script

El siguiente ejemplo muestra cómo generar un PDF en base64 y devolverlo, por ejemplo, como respuesta de un endpoint. En backend, `generatePDF` acepta `output: "base64"` (valor por defecto) o `"buffer"` — ver la [firma completa en la guía Single](/docs/es/guides/functions/generate-pdf/single).

```typescript
import { generatePDF } from "@react-pdf-levelup/core";
import Template from "./MyTemplate"; // Tu componente Template

const controllerX = async () => {
    try {
        const data = {
            nombre: "Juan Pérez",
            edad: 30,
            ciudad: "Madrid",
        };

        // 1. Generar el PDF en base64 (output: "base64" es el default en backend)
        const base64PDF = await generatePDF({ template: Template, data, output: "base64" });

        if (!base64PDF) {
            throw new Error("No se pudo generar el PDF");
        }

        return base64PDF;

    } catch (error) {
        console.error("Error al generar el PDF:", error);
    }
};

// Si necesitas el Buffer crudo en vez de base64:
// const bufferPDF = await generatePDF({ template: Template, data, output: "buffer" });
```

## Uso en API Endpoints (desde su backend).

Si estás utilizando Express, Next.js API Routes u otro servidor HTTP, puedes enviar el buffer directamente al cliente y decodificarlo en el frontend.

## No utilizo entorno de ejecución JavaScript/TypeScript

¿Puedo usar React PDF Level Up? Sí, puedes utilizar la API REST diseñada para generar los PDFs. Puedes encontrar la documentación de esta API en [este enlace](https://react-pdf-levelup.nimbux.cloud/docs/es/guides/api-rest/)
