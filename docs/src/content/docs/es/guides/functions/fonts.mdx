## Fuentes por defecto

Las siguientes fuentes están disponibles por defecto en `react-pdf-levelup` y no requieren registro:

- `Courier`
- `Courier-Bold`
- `Courier-Oblique`
- `Courier-BoldOblique`
- `Helvetica`
- `Helvetica-Bold`
- `Helvetica-Oblique`
- `Helvetica-BoldOblique`
- `Times-Roman`
- `Times-Bold`
- `Times-Italic`
- `Times-BoldItalic`

## Fuentes Personalizadas

Puedes registrar fuentes adicionales utilizando `Font.register`.

> **⚠️ IMPORTANTE**: Para asegurar que el PDF se genere correctamente en todos los entornos (especialmente al usar la API REST), las fuentes **DEBEN** cargarse desde **URLs remotas absolutas** (https://...). No utilices rutas locales del sistema de archivos.

### Ejemplo de registro

```ts
Font.register({
  family: "Lobster",
  fonts: [
    {
      src: "https://genarogg.github.io/react-pdf-levelup/public/font/Lobster-Regular.ttf",
      fontWeight: "normal",
    },
  ],
});
```

### Uso en estilos

Una vez registrada, puedes usar la fuente en tus estilos (`StyleSheet.create` o estilos en línea):

```tsx
<Layout style={{ fontFamily: 'Helvetica' }}>
  <H1>Título del Documento</H1>
  <P>Contenido del documento...</P>
</Layout>
```

## getFont

Función auxiliar para resolver la ruta de un archivo de fuente, de forma que funcione tanto en backend como en frontend sin importar desde qué archivo se llame.

No descarga ni parsea la fuente — solo **resuelve el `fontPath` a un valor utilizable** por `Font.register`, según el caso:

1. Si `fontPath` ya es una URL (`http://` o `https://`) → la devuelve tal cual, sin tocarla.
2. Si `fontPath` ya es una ruta absoluta (empieza con `/`, o con letra de unidad de Windows como `C:\` o `C:/`) → la devuelve tal cual.
3. Si se ejecuta en el navegador → la devuelve tal cual (no tiene sentido resolverla contra el filesystem en el browser).
4. En cualquier otro caso (backend + ruta relativa) → resuelve la ruta relativa **contra el directorio del archivo que llamó a `getFont`**, usando `callerImportMetaUrl` para saber desde dónde es relativa esa ruta.

### Firma

```typescript
getFont(fontPath: string, callerImportMetaUrl: string): Promise<string>
```

### Parámetros

| Nombre | Tipo | Descripción |
| :--- | :--- | :--- |
| `fontPath` | `string` | Ruta a la fuente: puede ser una URL, una ruta absoluta o una ruta relativa. |
| `callerImportMetaUrl` | `string` | El `import.meta.url` del archivo que llama a `getFont`. Se usa como base para resolver `fontPath` cuando es una ruta relativa en backend. |

> ℹ️ `callerImportMetaUrl` tiene que ser el `import.meta.url` de **quien llama** a `getFont`, no el de `getFont` mismo — así la ruta relativa se resuelve respecto al archivo del template, no respecto a la librería.

### Retorno

Retorna una promesa que resuelve a un `string`: la ruta final ya resuelta (URL, ruta absoluta, o la ruta relativa original si corre en el navegador).

### Ejemplo

```tsx
import { getFont } from '@react-pdf-levelup/core';
import { Font } from '@react-pdf/renderer';

// MyTemplate.tsx
const fontSrc = await getFont("./fonts/Lobster-Regular.ttf", import.meta.url);

Font.register({
  family: "Lobster",
  fonts: [{ src: fontSrc, fontWeight: "normal" }],
});
```

En este ejemplo, si `MyTemplate.tsx` corre en backend, `getFont` resuelve `"./fonts/Lobster-Regular.ttf"` a una ruta absoluta en disco relativa a la carpeta donde vive `MyTemplate.tsx`. Si corre en el navegador, devuelve la ruta tal cual, sin modificarla.
