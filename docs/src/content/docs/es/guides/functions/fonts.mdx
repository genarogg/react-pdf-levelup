## Fuentes por defecto

Las siguientes fuentes están disponibles por defecto en `react-pdf-levelup` y no requieren registro:

- `Courier`
- `Courier-Bold`
- `Courier-Oblique`
- `Courier-BoldOblique`
- `Helvetica`
- `Helvetica-Bold`
- `Helvetica-Oblique`
- `Helvetica-BoldOblique`
- `Times-Roman`
- `Times-Bold`
- `Times-Italic`
- `Times-BoldItalic`

## Fuentes Personalizadas

Puedes registrar fuentes adicionales utilizando `Font.register`.

> **⚠️ IMPORTANTE**: Para asegurar que el PDF se genere correctamente en todos los entornos (especialmente al usar la API REST), las fuentes **DEBEN** cargarse desde **URLs remotas absolutas** (https://...). No utilices rutas locales del sistema de archivos.

### Ejemplo de registro

```ts
Font.register({
  family: "Lobster",
  fonts: [
    {
      src: "https://genarogg.github.io/react-pdf-levelup/public/font/Lobster-Regular.ttf",
      fontWeight: "normal",
    },
  ],
});
```

### Uso en estilos

Una vez registrada, puedes usar la fuente en tus estilos (`StyleSheet.create` o estilos en línea):

```tsx
<Layout style={{ fontFamily: 'Helvetica' }}>
  <H1>Título del Documento</H1>
  <P>Contenido del documento...</P>
</Layout>
```

## getFont

Función asíncrona para recuperar datos de una fuente desde una URL.
Esta función es **experimental/beta** y podría estar sujeta a cambios.

### Firma

```typescript
getFont({ fontName, fontUrl }: { fontName: string, fontUrl: string }): Promise<Object>
```

### Parámetros

| Nombre | Tipo | Descripción |
| :--- | :--- | :--- |
| `fontName` | `string` | El nombre de la fuente a recuperar. |
| `fontUrl` | `string` | La URL desde donde se puede obtener la fuente. |

### Retorno

Retorna una promesa que resuelve con los datos de la fuente.

### Ejemplo

```tsx
import { getFont } from '@react-pdf-levelup/core';

const fetchMyFont = async () => {
  const fontData = await getFont({
    fontName: "Open Sans",
    fontUrl: "https://fonts.gstatic.com/s/opensans/v17/mem8YaGs126MiZpBA-UFVZ0e.ttf",
  });
  console.log("Datos de la fuente:", fontData);
};
```
