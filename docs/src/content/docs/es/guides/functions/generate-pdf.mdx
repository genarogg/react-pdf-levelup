## generatePDF

Función asíncrona para generar un PDF a partir de un componente React. Detecta automáticamente el entorno de ejecución (backend/Node o frontend/navegador) y adapta tanto los formatos de salida disponibles como el comportamiento por defecto a ese entorno.

### Firma

```typescript
// Backend (Node)
generatePDF({ template, data, output }: {
  template: React.ElementType;
  data?: any;
  output?: "base64" | "buffer"; // default: "base64"
}): Promise<string | Buffer>

// Frontend (navegador)
generatePDF({ template, data, output, fileName }: {
  template: React.ElementType;
  data?: any;
  output?: "blob" | "url" | "download"; // default: "download"
  fileName?: string; // solo aplica con output: "download"
}): Promise<Blob | string | void>
```

### Parámetros

| Nombre | Tipo | Descripción |
| :--- | :--- | :--- |
| `template` | `React.ElementType` | El componente React que representa el documento PDF. |
| `data` | `any` | Opcional. Datos que se pasan como prop `data` al componente `template`. |
| `output` | `string` | Opcional. Formato de salida. En backend: `"base64"` (default) \| `"buffer"`. En frontend: `"blob"` \| `"url"` \| `"download"` (default). |
| `fileName` | `string` | Opcional, solo frontend con `output: "download"`. Nombre del archivo descargado. Por defecto `"document.pdf"`. |

### Retorno

- **Backend**: una promesa que resuelve a `string` (base64) o `Buffer`, según `output`.
- **Frontend**: una promesa que resuelve a `Blob`, `string` (URL de objeto) o `void` (cuando `output: "download"`, que dispara la descarga directamente).

### Ejemplo (backend)

```tsx
import { generatePDF } from '@react-pdf-levelup/core';
import MyDocument from './MyDocument';

const base64 = await generatePDF({
  template: MyDocument,
  data: { name: "John Doe" },
});
```

### Ejemplo (frontend)

```tsx
import { generatePDF } from '@react-pdf-levelup/core';
import MyDocument from './MyDocument';

// Por defecto dispara la descarga del PDF en el navegador
await generatePDF({
  template: MyDocument,
  data: { name: "John Doe" },
  fileName: "mi-documento.pdf",
});
```

## decodePDF

Recibe un PDF ya generado (en base64, `Buffer` o `Blob` — lo que sea que haya devuelto `generatePDF`) y lo procesa según el entorno: en frontend lo descarga y/o lo abre en una pestaña nueva; en backend lo guarda en disco.

### Firma

```typescript
decodePDF({ pdf, name, download, showBlob, saveSRC }: {
  pdf: string | Buffer | Blob;
  name: string;
  download?: boolean;  // frontend, default true
  showBlob?: boolean;  // frontend, default true
  saveSRC?: string;    // backend, requerido
}): Promise<void>
```

### Parámetros

| Nombre | Tipo | Descripción |
| :--- | :--- | :--- |
| `pdf` | `string \| Buffer \| Blob` | El PDF a procesar, en base64, `Buffer` o `Blob`. |
| `name` | `string` | Nombre del archivo. Se le agrega `.pdf` automáticamente si falta. |
| `download` | `boolean` | Opcional, solo frontend. Si dispara la descarga automática. Por defecto `true`. |
| `showBlob` | `boolean` | Opcional, solo frontend. Si abre el PDF en una pestaña nueva. Por defecto `true`. |
| `saveSRC` | `string` | Requerido en backend. Ruta de disco donde guardar el PDF. Sin este parámetro, `decodePDF` lanza un error en backend. |

### Retorno

Retorna una promesa que resuelve a `void` una vez que el PDF fue guardado, descargado y/o abierto según corresponda.

### Ejemplo

```tsx
import { generatePDF, decodePDF } from '@react-pdf-levelup/core';
import MyDocument from './MyDocument';

const base64 = await generatePDF({ template: MyDocument, data: { name: "John Doe" } });

await decodePDF({
  pdf: base64,
  name: "documento", // se guarda como "documento.pdf"
});
```

## Funciones Re-exportadas de @react-pdf/renderer

Las siguientes funciones son re-exportadas directamente desde la librería `@react-pdf/renderer` para facilitar su uso. Para una documentación detallada, por favor, consulte la [documentación oficial de React-PDF](https://react-pdf.org/).

- **`pdf`**: El componente principal para crear documentos PDF.
- **`renderToStream`**: Renderiza un documento PDF a un stream de Node.js.
- **`renderToBuffer`**: Renderiza un documento PDF a un Buffer.
- **`renderToFile`**: Renderiza un documento PDF directamente a un archivo en el sistema de archivos.
- **`usePDF`**: Un hook de React para renderizar documentos PDF en el navegador.
