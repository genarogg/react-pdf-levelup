## generatePDF

Función asíncrona para generar un PDF a partir de un componente React y, opcionalmente, descargarlo.
Esta es una nueva función desarrollada específicamente para este proyecto.

### Firma

```typescript
generatePDF({ document, fileName, download }: { document: React.ElementType, fileName: string, download?: boolean }): Promise<void>
```

### Parámetros

| Nombre | Tipo | Descripción |
| :--- | :--- | :--- |
| `document` | `React.ElementType` | El componente React que representa el documento PDF. |
| `fileName` | `string` | El nombre deseado para el archivo PDF generado. |
| `download` | `boolean` | Opcional. Si es `true`, el PDF se descargará automáticamente. Por defecto es `true`. |

### Retorno

Retorna una promesa que resuelve a `void` cuando el PDF ha sido generado y, opcionalmente, descargado.

### Ejemplo

```tsx
import { generatePDF } from '@react-pdf-levelup/core';
import MyDocument from './MyDocument';

const handleGenerateAndDownload = async () => {
  await generatePDF({ 
    document: <MyDocument />, 
    fileName: "mi-documento.pdf",
    download: true
  });
  console.log("PDF generado y descargado");
};
```

## decodePDF

Decodifica un documento PDF desde una URL dada.
Esta es una nueva función desarrollada específicamente para este proyecto.

### Firma

```typescript
decodePDF(url: string, options?: Object): Promise<Object>
```

### Parámetros

| Nombre | Tipo | Descripción |
| :--- | :--- | :--- |
| `url` | `string` | La URL del documento PDF a decodificar. |
| `options` | `Object` | Opcional. Configuraciones adicionales para la decodificación. |

### Retorno

Retorna una promesa que resuelve con el objeto PDF decodificado.

### Ejemplo

```tsx
import { decodePDF } from '@react-pdf-levelup/core';

const handleDecodePDF = async () => {
  const pdfDoc = await decodePDF("https://example.com/document.pdf");
  console.log("PDF decodificado:", pdfDoc);
};
```

## generatePDFonWorker

Genera un documento PDF utilizando un *web worker*.
Esta función es **experimental/beta** y podría estar sujeta a cambios.
Descarga la generación del PDF a un hilo de trabajo para evitar bloquear el hilo principal de la UI.

### Firma

```typescript
generatePDFonWorker(props: Object): Promise<Blob>
```

### Parámetros

| Nombre | Tipo | Descripción |
| :--- | :--- | :--- |
| `props` | `Object` | Las propiedades para generar el PDF en un worker. |

### Retorno

Retorna una promesa que resuelve con un `Blob` conteniendo los datos del PDF.

### Ejemplo

```tsx
import { generatePDFonWorker } from '@react-pdf-levelup/server';
import MyDocument from './MyDocument';

const handleGenerateWorker = async () => {
  const pdfBlob = await generatePDFonWorker({
    document: <MyDocument />,
    // otras propiedades para el worker
  });
  console.log("PDF generado en worker:", pdfBlob);
};
```

## Funciones Re-exportadas de @react-pdf/renderer

Las siguientes funciones son re-exportadas directamente desde la librería `@react-pdf/renderer` para facilitar su uso. Para una documentación detallada, por favor, consulte la [documentación oficial de React-PDF](https://react-pdf.org/).

- **`pdf`**: El componente principal para crear documentos PDF.
- **`renderToStream`**: Renderiza un documento PDF a un stream de Node.js.
- **`renderToBuffer`**: Renderiza un documento PDF a un Buffer.
- **`renderToFile`**: Renderiza un documento PDF directamente a un archivo en el sistema de archivos.
- **`usePDF`**: Un hook de React para renderizar documentos PDF en el navegador.
