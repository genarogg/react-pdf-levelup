# QR

El componente `QR` permite generar códigos QR simples con la opción de incrustar un logo en el centro. Es útil para añadir información codificada de forma rápida y sencilla a tus documentos PDF.

Usa su propio motor de generación (`generateQRAsBase64`, basado en la librería `qrcode`), independiente del motor de `QRstyle` (basado en `qr-code-styling`). Si necesitás personalización avanzada de esquinas, puntos o imagen central con más control, usá [QRstyle](/docs/es/plugin/qr/qrstyle) en su lugar.

### Props

| Nombre               | Tipo                               | Default           | Descripción                                           |
| :------------------- | :--------------------------------- | :---------------- | :----------------------------------------------------- |
| `url`              | `string`                           | `""`              | El texto o URL que se codificará en el código QR.     |
| `size`               | `number`                           | `150`             | Tamaño del código QR en píxeles (ancho y alto).       |
| `style`              | `any`                              | `{}`              | Estilos adicionales para el contenedor del código QR. |
| `colorDark`          | `string`                           | `"#000000"`       | Color de los módulos (puntos) oscuros del código QR.  |
| `colorLight`         | `string`                           | `"#ffffff"`       | Color de fondo del código QR.                         |
| `margin`             | `number`                           | `0`               | Margen alrededor del código QR en píxeles.           |
| `logo`               | `string`                           | `undefined`       | URL de la imagen del logo a incrustar en el centro del QR. Si se omite, no se incrusta ningún logo. |
| `logoWidth`          | `number`                           | `size * 0.2`      | Ancho del logo en píxeles.                            |
| `logoHeight`         | `number`                           | `size * 0.2`      | Alto del logo en píxeles.                             |
| `errorCorrectionLevel` | `"L" \| "M" \| "Q" \| "H"` | `"M"`             | Nivel de corrección de errores del código QR. Permite recuperar datos si el código está dañado. Si vas a incrustar un logo, se recomienda usar `"H"` para mayor tolerancia a la oclusión. |
| `debug` | `boolean` | `false` | Activa el modo debug (bordes). |
| `fixed` | `boolean` | `false` | Indica si el elemento debe aparecer en todas las páginas. |
| `break` | `boolean` | `false` | Fuerza un salto de página antes del elemento. |

> **Nota sobre `logo`:** cuando se pasa `logo`, el componente genera primero el QR base y luego incrusta la imagen del logo sobre un canvas (vía `addLogoToQR`), recortando un fondo blanco alrededor del logo para mantener el contraste. En Node (SSR / generación en backend) esto requiere el paquete `canvas` disponible en el entorno; en el navegador usa el `canvas` nativo. Si `canvas` no está disponible en Node, el QR se genera igualmente mostrando el resultado sin el logo.

### Ejemplo

```tsx
import { QR } from '@react-pdf-levelup/core';

function MyQRCode() {
  return (
    <QR
      url="https://react-pdf-levelup.com"
      size={200}
      colorDark="#1a202c"
      colorLight="#f7fafc"
      margin={5}
      logo="https://picsum.photos/id/237/200/200"
      logoWidth={40}
      logoHeight={40}
      errorCorrectionLevel="H"
    />
  );
}
```

### QR sin logo

```tsx
<QR url="https://react-pdf-levelup.com" size={150} />
```
