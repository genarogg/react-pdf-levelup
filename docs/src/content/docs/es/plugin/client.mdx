# Plugin Cliente (`@react-pdf-levelup/client`)

> ℹ️ **Confirmado contra el código fuente:** `@react-pdf-levelup/client` es un paquete real que re-exporta `generatePDF`, `decodePDF` y `getFont` desde el mismo origen que `@react-pdf-levelup/core` (`frontend/src/functions`). Es un subconjunto de `core` — no incluye los componentes PDF (`Layout`, `Table`, `Button`, etc.), ni las funciones de worker (esas viven en `@react-pdf-levelup/server`). `printBase64Pdf` **no** aparece en el código fuente de `client` relevado para esta revisión — si tu instalación la expone, confirmalo contra el `package.json`/exports real de tu versión.

El plugin `@react-pdf-levelup/client` expone las funciones de generación y manejo de PDF sin traer consigo los componentes de `core`, útil cuando solo necesitás `generatePDF`/`decodePDF`/`getFont` en el cliente.

## Funciones Exportadas

### `generatePDF`

Genera un documento PDF a partir de un componente React, detectando automáticamente si corre en backend o frontend. Es la misma función que la documentada en `@react-pdf-levelup/core`.

- [Ver documentación detallada de `generatePDF`](/docs/es/guides/functions/generate-pdf/single)

### `decodePDF`

Toma un PDF ya generado (base64, `Buffer` o `Blob`) y lo procesa según el entorno: en frontend lo descarga y/o lo abre en una pestaña nueva; en backend lo guarda en disco.

- [Ver documentación detallada de `decodePDF`](/docs/es/guides/functions/generate-pdf/single#decodepdf)

### `getFont`

Resuelve la ruta de un archivo de fuente para poder registrarla con `Font.register`, ajustándose automáticamente según el entorno (URL, ruta absoluta, navegador o Node).

- [Ver documentación detallada de `getFont`](/docs/es/guides/functions/fonts)

### `printBase64Pdf` <Badge text="no confirmado" variant="caution" />

Función mencionada en versiones anteriores de esta documentación para imprimir un PDF a partir de un string en Base64 (creando un iframe oculto y disparando el diálogo de impresión del navegador). No aparece en el código fuente de `client` relevado para esta revisión — confirmá si existe en tu instalación antes de usarla.

- **Parámetros**: `base64Data` (string) - Una cadena PDF codificada en Base64
- **Retorna**: void

## Uso

```tsx
import { generatePDF, decodePDF } from '@react-pdf-levelup/client';
import { Layout, P } from '@react-pdf-levelup/core';

const myTemplate = ({ data }) => {
  return (
    <Layout>
      <P>Hola, {data.name}</P>
    </Layout>
  );
};

async function createAndDownloadPdf() {
  const data = { name: 'Mundo' };
  const base64Pdf = await generatePDF({ template: myTemplate, data });
  await decodePDF({ pdf: base64Pdf, name: 'mi-documento' });
}

createAndDownloadPdf();
```
