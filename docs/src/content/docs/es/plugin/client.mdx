# Plugin Cliente (`@react-pdf-levelup/client`)

> ⚠️ **Nota de consistencia (no verificado contra el código fuente de `core`):** este documento describe `generatePDF`, `decodeBase64Pdf` y `printBase64Pdf` como parte de un paquete separado `@react-pdf-levelup/client`. Sin embargo, `guides/functions/generate-pdf/single.mdx` documenta las mismas dos primeras funciones (como `generatePDF`/`decodePDF`) importándolas directamente desde `@react-pdf-levelup/core`. Ninguna de las dos funciones aparece en el código fuente de `core` relevado para esta auditoría, por lo que no fue posible confirmar cuál de las dos rutas de importación es la correcta (pueden vivir en un paquete del monorepo no incluido en esta revisión). **Antes de usar este ejemplo, confirmá el paquete real consultando el `package.json`/exports de tu instalación**, o usá la ruta `@react-pdf-levelup/core` documentada en la [guía de Single](/es/guides/functions/generate-pdf/single), que es consistente con el resto de componentes de este sitio.

El plugin `@react-pdf-levelup/client` proporciona un conjunto de funciones de utilidad diseñadas para la interacción con PDFs en entornos de cliente (navegadores o Node.js). Exporta funciones de utilidad incluyendo `generatePDF`, `decodeBase64Pdf` y `printBase64Pdf`.

## Funciones Exportadas

### `generatePDF`

Esta función te permite generar un documento PDF a partir de un componente React. Es la misma función que se describe en la documentación principal de funciones.

- [Ver documentación detallada de `generatePDF`](/es/guides/functions/generate-pdf/single)

### `decodeBase64Pdf`

Esta función ayuda a decodificar una cadena Base64 que representa un PDF y a ofrecerlo para descarga al usuario. Es la misma función que se describe en la documentación principal de funciones, bajo el nombre `decodePDF`.

- [Ver documentación detallada de `decodePDF`](/es/guides/functions/generate-pdf/single#decodepdf)

### `printBase64Pdf`

Esta función imprime un documento PDF a partir de una cadena codificada en Base64. Crea un iframe oculto, carga el PDF y abre el diálogo de impresión del navegador para que el usuario pueda imprimir o guardar el documento.

- **Parámetros**: `base64Data` (string) - Una cadena PDF codificada en Base64
- **Retorna**: void

## Uso

Para usar estas funciones, simplemente impórtalas desde el paquete `@react-pdf-levelup/client` (o desde `@react-pdf-levelup/core`, ver nota de advertencia arriba, según cómo esté configurado tu proyecto):

```tsx
import { generatePDF, decodeBase64Pdf } from '@react-pdf-levelup/client';
import { Layout, P } from '@react-pdf-levelup/core';

// Ejemplo de uso de generatePDF
const myTemplate = ({ data }) => {
  return (
    <Layout>
      <P>Hola, {data.name}</P>
    </Layout>
  );
};

async function createAndDownloadPdf() {
  const data = { name: 'Mundo' };
  const base64Pdf = await generatePDF({ template: myTemplate, data });
  if (base64Pdf) {
    decodeBase64Pdf(base64Pdf, 'mi-documento.pdf');
  }
}

createAndDownloadPdf();
```
