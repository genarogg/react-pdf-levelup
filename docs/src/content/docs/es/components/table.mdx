# Table

Los componentes `Table`, `Thead`, `Tbody`, `Tr`, `Th` y `Td` proporcionan un sistema completo de tablas para documentos PDF, con estilos predefinidos, filas zebra, cabeceras, soporte de bordes redondeados y división automática por páginas.

---

## Table

Contenedor principal. Inyecta un contexto compartido (`TableContext`) con colores, tamaños y modo de cuadrícula, y controla el renderizado de bordes/esquinas redondeadas y la paginación manual mediante `rowsPerPage`.

### Props

| Nombre               | Tipo                                                                       | Default     | Descripción                                                                                                                                                                                                                                |
| :------------------- | :------------------------------------------------------------------------- | :---------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `children`           | `React.ReactNode`                                                          | `N/A`       | Contenido de la tabla. Estructura recomendada: un `Thead` + un `Tbody` con `Tr` adentro.                                                                                                                                                  |
| `style`              | `any`                                                                      | `{}`        | Estilos adicionales del contenedor exterior (se pasa a un `View`). **Nota:** si `style` incluye un `borderRadius` explícito, se activa automáticamente el workaround del bug de border-radius (issue #395 de `@react-pdf/renderer`).       |
| `cellHeight`         | `number`                                                                   | `22`        | Altura mínima (`minHeight`) por defecto de las celdas que no declaren su propio `height`.                                                                                                                                                 |
| `borderColor`        | `string`                                                                   | `"#000"`    | Color del borde exterior y de la cuadrícula interna. También se usa como fallback cuando el usuario no especifica un color de borde propio en `style`.                                                                                     |
| `textColor`          | `string`                                                                   | `"#000"`    | Color del texto por defecto en toda la tabla (puede sobreescribirse por `Thead`, `Tbody` o cada celda individual).                                                                                                                         |
| `headerBackground`   | `string`                                                                   | `"#ccc"`    | Color de fondo del contenedor del encabezado (`Thead`).                                                                                                                                                                                   |
| `zebra`              | `boolean`                                                                  | `true`      | Habilita el patrón zebra (filas impares con fondo alternado).                                                                                                                                                                             |
| `zebraColor`         | `string`                                                                   | `"#eeeeee"` | Color de fondo usado para las filas impares cuando `zebra: true`. Sólo afecta a `Td` — `Th` nunca se zebra.                                                                                                                               |
| `grid`               | `"grid" \| "modern" \| "not-grid"`                                         | `"grid"`    | Estilo de la cuadrícula interna: **grid** → bordes completos, **modern** → sólo bordes inferiores entre filas, **not-grid** → sin bordes internos (se compensa con padding para no alterar el tamaño de celda).                             |
| `borderRadiusMethod` | `"view" \| "svg"`                                                          | `"view"`    | Qué implementación usar para el workaround del bug de `borderRadius`. `"view"` simula el borde con un `View` exterior de relleno; `"svg"` dibuja el contorno con un trazo SVG superpuesto (permite interior transparente).                |
| `rowsPerPage`        | `Array<{ nRow: number; break?: boolean }>`                                 | `undefined` | Si se provee, **divide el `Tbody` en varias tablas independientes**, una por cada "tanda" de filas, repitiendo el `Thead` en cada una y con bordes/redondeos propios. Ver abajo la sección dedicada.                                        |
| `[key: string]`      | `any`                                                                      | —           | Cualquier otra prop de `View` de `@react-pdf/renderer`: `wrap`, `break`, `id`, `fixed`, `debug`, etc.                                                                                                                                      |

### Modos de cuadrícula (`grid`)

| Modo         | Borde derecho entre columnas | Borde inferior entre filas | Borde exterior |
| :----------- | :--------------------------- | :------------------------- | :------------- |
| `"grid"`     | ✅ (todas menos la última)   | ✅ (todas menos última fila) | ✅ (por `Table`) |
| `"modern"`   | ❌                           | ✅ (todas menos última fila) | ✅ (por `Table`) |
| `"not-grid"` | ❌ (compensado con padding)  | ❌ (compensado con padding) | ✅ (por `Table`) |

### Workaround de `borderRadius` (bug #395 de `@react-pdf/renderer`)

`@react-pdf/renderer` distorsiona las curvas de las esquinas cuando una misma `View` combina `borderWidth` (stroke real) + `borderRadius`. Para evitarlo, cuando `style` trae un `borderRadius` explícito, `Table` **no usa border real** en el contenedor exterior. En su lugar aplica uno de estos dos métodos, seleccionables con `borderRadiusMethod`:

- **`"view"`** (default): arma un "sándwich" — una `View` exterior con `backgroundColor: borderColor` + `padding: borderWidth` + `borderRadius`, y dentro el contenido real con un `backgroundColor` propio. Simple y robusto. **Limitación:** el interior de la tabla queda SIEMPRE con algún `backgroundColor` (forzado por la capa intermedia) — no puede ser 100% transparente.

- **`"svg"`**: deja el contenido "hueco" y dibuja **arriba** del mismo, superpuesto, un contorno formado por 4 arcos SVG de esquina + 4 rectas `View` que unen las esquinas. **Ventaja:** el interior de la tabla permanece transparente si el usuario no especificó ningún `backgroundColor` en `style`, y no sufre el límite práctico de radio ≈12 del método "view". **Limitación:** usa 8 piezas, una sintaxis más compleja por dentro.

La activación del fix es **automática por `borderRadius`**, no por `borderRadiusMethod`. Si `style` no tiene `borderRadius`, ninguno de los dos métodos se aplica — la tabla usa `borderWidth` normal como siempre.

> ⚠️ Limitación conocida (método "view"): con `borderRadius` por encima de ~12, la aproximación de dos Views anidadas puede mostrar una pequeña desalineación visual en las esquinas. Para radios grandes usá preferentemente `borderRadiusMethod: "svg"`.

### División manual por páginas (`rowsPerPage`)

Por defecto `@react-pdf/renderer` parte las tablas "donde le queda bien", sin cerrar ni reabrir prolijamente los bordes ni repetir la cabecera. Para controlar esto de forma precisa, `Table` cuenta con `rowsPerPage`.

**Cómo usarlo:** pasá un array de entradas, una por tanda, donde cada entrada define:

- `nRow`: **cuántas filas de esta tabla entran** en esa página (no acumulado).
- `break` (opcional, default `false`): si antes de renderizar **esa** tanda hay que forzar un salto de página.

Si el `Tbody` tiene más filas que las que cubren tus entradas, el sobrante se sigue cortando **repitiendo la última entrada** (mismo `nRow` y mismo `break`) hasta terminar.

Reglas importantes:
- Mientras `rowsPerPage` produzca un split real, la prop `break` de nivel `Table` se ignora — cada tanda controla su propio salto con su `break` interno.
- Si la estructura no es `Thead + Tbody` (por ejemplo, si `children` no tiene esos componentes), `rowsPerPage` se desactiva silenciosamente y cae al comportamiento normal.
- Cada tanda renderiza su propio `Thead` y su propio borde/radio de punta a punta — como si hubieras escrito N `<Table>` a mano.

## Thead

Sección del encabezado. Renderiza un `View` con `backgroundColor: headerBackground` del contexto, aplica `borderTopLeftRadius` / `borderTopRightRadius` cuando el fix de border-radius está activo, y sobreescribe el contexto de `textAlign`, `borderColor` y `textColor` para todos sus descendientes.

### Props

| Nombre        | Tipo                               | Default          | Descripción                                                                   |
| :------------ | :--------------------------------- | :--------------- | :---------------------------------------------------------------------------- |
| `children`    | `React.ReactNode`                  | `N/A`            | Filas del encabezado (generalmente uno o más `Tr` con `Th` adentro).         |
| `style`       | `any`                              | `{}`             | Estilos adicionales del contenedor del encabezado.                            |
| `textAlign`   | `"left" \| "center" \| "right"`    | `"left"`         | Alineación por defecto de las celdas del encabezado (sobrescribe el Table).   |
| `borderColor` | `string`                           | `(del contexto)` | Sobrescribe el `borderColor` heredado de `Table` para este `Thead`.           |
| `textColor`   | `string`                           | `(del contexto)` | Sobrescribe el `textColor` heredado de `Table` para este `Thead`.             |
| `[key: string]` | `any`                            | —                | Cualquier otra prop de `View` (wrap, break, id, fixed, debug, etc.).          |

### Ejemplo

```tsx
<Thead textAlign="center" textColor="#fff" borderColor="#4338ca">
  <Tr>
    <Th>Nombre</Th>
    <Th>Edad</Th>
  </Tr>
</Thead>
```

## Tbody

Sección del cuerpo. Por cada `Tr` que contiene le inyecta vía `cloneElement`:

- `isLastRow: idx === count - 1` (usado por `Cell` para redondear esquinas inferiores y/o remover el borde inferior de la última fila).
- `isOdd: idx % 2 === 1` (usado por `Td` para aplicar zebra).
- Cualquier `[key: string]` extra que pases al `Tbody` se propaga tal cual a cada `Tr`.

### Props

| Nombre         | Tipo              | Default          | Descripción                                                            |
| :------------- | :---------------- | :--------------- | :--------------------------------------------------------------------- |
| `children`     | `React.ReactNode` | `N/A`            | Filas del cuerpo (componentes `Tr` con `Td` adentro).                 |
| `borderColor`  | `string`          | `(del contexto)` | Sobrescribe `borderColor` del contexto para este `Tbody`.             |
| `textColor`    | `string`          | `(del contexto)` | Sobrescribe `textColor` del contexto para este `Tbody`.               |
| `[key: string]`| `any`             | —                | Cualquier otra prop se propaga tal cual a cada `Tr` interno.          |

## Tr

Fila de tabla (tanto dentro de `Thead` como de `Tbody`). Su responsabilidad principal es **calcular el ancho real de cada celda**, porque `@react-pdf/renderer` no tiene motor de tabla nativo (todo es flexbox):

- Suma las "unidades de columna" de la fila: cada celda cuenta `colSpan` (default `1`) como tantas unidades.
- Por cada celda: si la celda ya trae su propio `width` manual, se respeta. Si no, calcula un `width` porcentual: `100% * colSpan / totalUnits`.
- Además, pasa a cada celda mediante `cloneElement`: `width`, `isFirst`, `isLast`, y reenvía `isLastRow` / `isOdd` que le llegaron desde `Tbody`.

### Props

| Nombre          | Tipo              | Default     | Descripción                                                                         |
| :-------------- | :---------------- | :---------- | :---------------------------------------------------------------------------------- |
| `children`      | `React.ReactNode` | `N/A`       | Celdas de la fila (`Th` o `Td`).                                                    |
| `style`         | `any`             | `{}`        | Estilos adicionales del `View` de la fila.                                          |
| `isLastRow`     | `boolean`         | `false`     | Indica si es la última fila del `Tbody`. Inyectado por `Tbody`, pero se puede setear a mano si usás `Tr` suelto. |
| `isOdd`         | `boolean`         | `false`     | Indica si es una fila impar (para zebra). Inyectado por `Tbody`.                    |
| `[key: string]` | `any`             | —           | Cualquier otra prop de `View`.                                                      |

## Th y Td

`Th` (celda de encabezado) y `Td` (celda de datos) son wrappers idénticos sobre un mismo componente interno `Cell`, que sólo difieren en:

1. **`Th`** usa `styles.th` (`fontWeight: bold`) y **nunca** aplica zebra ni redondea esquinas inferiores.
2. **`Td`** usa `styles.td`, aplica zebra si `zebra && isOdd`, y redondea las esquinas inferiores de la última fila cuando hay `borderRadius`.

Ambos comparten la siguiente API pública:

### Props comunes a Th y Td

| Nombre          | Tipo                               | Default          | Descripción                                                                                                                                                                                                                                                              |
| :-------------- | :--------------------------------- | :--------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `children`      | `React.ReactNode`                  | `undefined`      | Contenido de la celda. Puede ser string, número, o componentes.                                                                                                                                                                                                          |
| `style`         | `any`                              | `{}`             | Estilos adicionales del `View` contenedor de la celda. Se aplica al final, después de los estilos base.                                                                                                                                                                  |
| `width`         | `string \| number`                 | `undefined`      | **Ancho explícito** de la celda. Si no se provee, `Tr` calcula automáticamente el ancho proporcional por `colSpan`. Valores válidos: `"100%"`, `"120px"`, `120` (número = puntos). Este valor **tiene prioridad** sobre el cálculo automático — una celda con `width` no entra en `totalUnits`. |
| `height`        | `string \| number`                 | `(cellHeight)`   | **Alto mínimo** de la celda (se aplica como `minHeight` al `View`). Si no se provee, usa el `cellHeight` del `TableContext` (default 22).                                                                                                                                |
| `colSpan`       | `number`                           | `1`              | Cantidad de columnas que "abarca" la celda, en unidades lógicas. Sólo afecta el **ancho** (es horizontal, dentro de la misma fila) — no hay fusión real de celdas, simplemente una celda proporcionalmente más ancha. **`rowSpan` no existe / no está soportado.**    |
| `textAlign`     | `"left" \| "center" \| "right"`    | `(del contexto)` | Alineación del texto. Precedencia: valor explícito en la celda → valor del `Thead`/contexto → `"left"` por defecto.                                                                                                                                                      |
| `text`          | `boolean`                          | `true`           | **Fundamental.** Si es `true` (default), el contenido se envuelve en un `<Text>` antes de ser renderizado (correcto para strings/números). **Ponelo en `false` cuando `children` sea un componente basado en `View`** (ej.: un `Badge`), porque `Text` no puede contener `View` en `@react-pdf/renderer`. |
| `isFirst`       | `boolean`                          | `false`          | Inyectado por `Tr`. Indica si es la primera celda de la fila (usado para remover `borderRightWidth` y para `borderBottomLeftRadius` en la última fila). Se puede sobreescribir manualmente si usás `Td`/`Th` fuera de un `Tr`.                                             |
| `isLast`        | `boolean`                          | `false`          | Inyectado por `Tr`. Análogo al anterior.                                                                                                                                                                                                                                 |
| `isLastRow`     | `boolean`                          | `false`          | Inyectado por `Tbody` → `Tr`. Usado para redondear esquinas inferiores y para remover `borderBottomWidth` en modo grid.                                                                                                                                                  |
| `isOdd`         | `boolean`                          | `false`          | Inyectado por `Tbody` → `Tr`. Indica si la fila es impar, para aplicar zebra en `Td`.                                                                                                                                                                                    |
| `[key: string]` | `any`                              | —                | Cualquier otra prop de `View` (o `Text` si `text=true`): `wrap`, `break`, `id`, `fixed`, `debug`, etc.                                                                                                                                                                   |

### Notas importantes

- **rowSpan no soportado:** la tabla está armada con `View` (flexbox) pura de `@react-pdf/renderer` y cada `Tr` es un hermano independiente del anterior, sin visibilidad de las columnas "ocupadas" entre filas. No hay forma limpia de hacer fusión vertical sin romper el flujo de paginado de PDF. Si necesitás ese efecto visual, usá un `View` posicionado manualmente por fuera del esquema `Tr`/`Td`.
- **text=false:** si tu celda contiene un componente basado en `View` (p. ej. un badge estilado con `View` redondo interior), **siempre** poné `text={false}`. De lo contrario `@react-pdf/renderer` romperá el render porque intenta anidar un `View` dentro de un `Text`.
- **colSpan se resuelve en Tr:** `Cell` recibe `colSpan` sólo para excluirlo de las props que se pasan al `View` nativo; el cálculo real del ancho ocurre en `Tr`. No hace nada si `Td` tiene `width` explícito.
