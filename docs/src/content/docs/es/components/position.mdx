## Left, Right, Center

Componentes de utilidad para alinear contenido horizontal y opcionalmente vertical. Todos (`Left`, `Right`, `Center`) comparten el mismo API. Se diferencian únicamente en la alineación horizontal por defecto.

- **Left**: Alinea contenido a la izquierda (`alignItems: "flex-start"`).
- **Right**: Alinea contenido a la derecha (`alignItems: "flex-end"`).
- **Center**: Alinea contenido al centro horizontalmente (`alignItems: "center"`).

Internamente son wrappers sobre `View` de `@react-pdf/renderer`.

### Props (comunes a Left, Right y Center)

| Nombre     | Tipo              | Default     | Descripción                                                                                                              |
| :--------- | :---------------- | :---------- | :----------------------------------------------------------------------------------------------------------------------- |
| `children` | `React.ReactNode` | `N/A`       | Contenido a alinear.                                                                                                     |
| `vertical` | `boolean`         | `false`     | Si es `true`, además centra verticalmente (`justifyContent: "center"`). Útil para contenido con altura conocida.         |
| `style`    | `any`             | `undefined` | Estilos adicionales (se mezclan al final).                                                                               |

Además, heredan todas las propiedades de `View` de `@react-pdf/renderer` (`debug`, `fixed`, `break`, etc.).

### Ejemplos

```tsx
import { Left, Right, Center, P, Div } from '@react-pdf-levelup/core';

// Alineación simple horizontal
<Left>
  <P>Texto a la izquierda</P>
</Left>

<Right>
  <P>Texto a la derecha</P>
</Right>

<Center>
  <P>Texto centrado</P>
</Center>

// Alineación horizontal + centrado vertical en un contenedor alto
<Div style={{ height: 120, backgroundColor: '#f0f0f0' }}>
  <Center vertical>
    <P>Centrado horizontal y vertical</P>
  </Center>
</Div>
```
