## Img

Componente para mostrar imágenes. Soporta todas las propiedades del componente `Image` de `@react-pdf/renderer`. Por defecto aplica `width: "100%"` y `height: "auto"`.

### Props

| Nombre | Tipo | Default | Descripción |
| :--- | :--- | :--- | :--- |
| `src` | `string` | `undefined` | URL o ruta de la imagen. |
| `style` | `object` | `{}` | Estilos adicionales. |
| `debug` | `boolean` | `false` | Activa el modo debug (bordes). |
| `fixed` | `boolean` | `false` | Indica si el elemento debe aparecer en todas las páginas. |
| `break` | `boolean` | `false` | Fuerza un salto de página antes del elemento. |

### Ejemplo

```tsx
import { Img } from '@react-pdf-levelup/core';

<Img src="https://picsum.photos/400/200" style={{ width: 200 }} />
```

## ImgBg

Imagen de fondo con contenido superpuesto. Coloca una imagen como capa de fondo absoluta y renderiza `children` encima.

### Props

| Nombre           | Tipo                                                              | Default    | Descripción                                                                       |
| :--------------- | :---------------------------------------------------------------- | :--------- | :-------------------------------------------------------------------------------- |
| `src`            | `string`                                                          | `N/A`      | **Requerido.** URL o ruta de la imagen de fondo.                                  |
| `width`          | `number \| string`                                                | `"100%"`   | Ancho del contenedor y la imagen.                                                 |
| `height`         | `number \| string`                                                | `"100%"`   | Alto del contenedor y la imagen.                                                  |
| `opacity`        | `number`                                                          | `0.2`      | Opacidad de la imagen de fondo (0 transparente — 1 opaca).                       |
| `objectFit`      | `"cover" \| "contain" \| "fill" \| "none" \| "scale-down"`       | `"cover"`  | Ajuste de la imagen en el contenedor.                                             |
| `objectPosition` | `"center" \| "top" \| "left" \| "right" \| "bottom"`             | `"center"` | Posición de la imagen.                                                            |
| `fixed`          | `boolean`                                                         | `false`    | Fija la imagen en todas las páginas (se pasa directamente a `Image.fixed`).       |
| `children`       | `React.ReactNode`                                                 | `N/A`      | Contenido que se renderiza sobre la imagen de fondo.                              |
| `style`          | `object`                                                          | `{}`       | Estilos adicionales para el contenedor.                                           |
| `debug`          | `boolean`                                                         | `false`    | Activa el modo debug (bordes).                                                    |
| `break`          | `boolean`                                                         | `false`    | Fuerza un salto de página antes del elemento.                                     |

Además, hereda todas las propiedades de `View` de `@react-pdf/renderer`.

### Ejemplo

```tsx
import { ImgBg, P, Center } from '@react-pdf-levelup/core';

<ImgBg
  src="https://picsum.photos/600/400"
  opacity={0.3}
  objectFit="cover"
  objectPosition="center"
>
  <Center>
    <P style={{ fontSize: 18, color: '#fff' }}>Texto sobre imagen de fondo</P>
  </Center>
</ImgBg>
```
