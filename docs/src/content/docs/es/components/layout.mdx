# Layout

El componente **Layout** es el núcleo estructural del documento PDF.

Internamente gestiona la configuración de página y envuelve el contenido con los componentes adecuados de `@react-pdf/renderer` y gestiona automáticamente:

- Tamaño de página
- Orientación
- Sistema de márgenes predefinidos
- Fondo de color o imagen
- Numeración automática
- Rejilla de referencia en centímetros
- Modo debug

---

## Props

| Nombre | Tipo | Default | Descripción |
|--------|------|---------|-------------|
| `size` | `PageSizeInput` (`PageSize \| { width: number; height: number }`) | `"A4"` | Tamaño de página. Puede ser un preset ISO/Americano o un objeto `{ width, height }` en puntos (72 dpi). |
| `orientation` | `"vertical" \| "horizontal" \| "portrait" \| "landscape" \| "h" \| "v"` | `"vertical"` | Orientación de la página. Internamente se transforma a `portrait` o `landscape`. |
| `backgroundColor` | `string` | `"white"` | Color de fondo de la página. |
| `backgroundImage` | `string` | `undefined` | URL de imagen de fondo que ocupa toda la página. |
| `backgroundImageOpacity` | `number` | `1` | Opacidad de la imagen de fondo (0–1). |
| `padding` | `number` | `30` | Padding base cuando `margin="normal"`. |
| `margin` | `MarginInput` (`"apa" \| "normal" \| "estrecho" \| "ancho" \| number`) | `"normal"` | Sistema de márgenes. Acepta un preset o un número en puntos para los 4 lados. |
| `style` | `object` | `{}` | Estilos adicionales para la página. |
| `footerLines` | `number` | `1` | Número de líneas reservadas abajo (usado por el contenedor de paginación para no solapar contenido). |
| `pagination` | `boolean` | `true` | Muestra numeración automática de páginas. |
| `paginationStyle` | `any` | `undefined` | Estilos adicionales para el `<Text>` de paginación dentro del footer (ej: `{ fontSize: 10, color: '#999' }`). |
| `rule` | `boolean` | `false` | Muestra rejilla de referencia en centímetros. |
| `debug` | `boolean` | `false` | Activa el modo debug de `@react-pdf/renderer`. |
| `dpi` | `number` | `undefined` | Resolución DPI de la página (se pasa directamente a `<Page dpi>` de `@react-pdf/renderer`). |
| `id` | `string` | `undefined` | ID HTML/CSS del elemento `<Page>` subyacente. |
| `meta` | `DocumentMeta` | `{}` | Metadatos del documento (título, autor, palabras clave, contraseñas, permisos, etc.). |

# Metadatos del Documento (`meta`)

El prop `meta` permite configurar los metadatos estándar del archivo PDF, que son visibles en las propiedades del documento en cualquier visor de PDF.

## Propiedades de `meta`

| Propiedad | Tipo | Descripción |
|-----------|------|-------------|
| `title` | `string` | Título del documento. |
| `author` | `string` | Autor del documento. |
| `subject` | `string` | Asunto del documento. |
| `keywords` | `string` | Palabras clave (separadas por espacios). |
| `creator` | `string` | Aplicación que creó el documento (Default: `react-pdf-levelup`). |
| `producer` | `string` | Aplicación que produjo el PDF (Default: `react-pdf-levelup`). |
| `pdfVersion` | `"1.3" \| "1.4" \| "1.5" \| "1.6" \| "1.7" \| "1.7ext3"` | Versión del estándar PDF. |
| `language` | `string` | Idioma del documento (ej: `es-ES`). |
| `pageMode` | `string` | Cómo se debe mostrar el documento al abrirlo (`useNone`, `useOutlines`, `useThumbs`, `fullScreen`). |
| `pageLayout` | `string` | El diseño de página a utilizar (`singlePage`, `oneColumn`, `twoColumnLeft`, `twoColumnRight`). |
| `creationDate` | `Date` | Fecha de creación del documento. |
| `modificationDate` | `Date` | Fecha de última modificación del documento. |
| `ownerPassword` | `string` | Contraseña de propietario (para proteger el PDF). |
| `userPassword` | `string` | Contraseña de usuario (para abrir el PDF). |
| `permissions` | `DocumentPermissions` | Permisos granulares del documento (ver tabla abajo). |
| `onRender` | `(props: { blob?: Blob }) => any` | Callback ejecutado cuando el documento termina de renderizarse, recibe el `Blob` del PDF. |

### Permisos (`DocumentPermissions`)

| Propiedad | Tipo | Descripción |
|-----------|------|-------------|
| `printing` | `"lowResolution" \| "highResolution"` | Permite imprimir el documento en baja o alta resolución. Si se omite, la impresión no está permitida. |
| `modifying` | `boolean` | Permite modificar el contenido del documento. |
| `copying` | `boolean` | Permite copiar/extraer texto e imágenes. |
| `annotating` | `boolean` | Permite agregar o modificar anotaciones. |
| `fillingForms` | `boolean` | Permite rellenar campos de formulario. |
| `contentAccessibility` | `boolean` | Permite extraer contenido para accesibilidad (lectores de pantalla). |
| `documentAssembly` | `boolean` | Permite ensamblar el documento (insertar, rotar o borrar páginas). |

## Ejemplo de uso de `meta`

```tsx
<Layout
  meta={{
    title: "Factura #1234",
    author: "Mi Empresa S.A.",
    subject: "Facturación Mensual",
    keywords: "factura pdf react",
    language: "es-ES"
  }}
>
  {/* Contenido */}
</Layout>
```

# Sistema de Márgenes

El Layout incluye un sistema de márgenes predefinidos para facilitar la maquetación.

## `margin="normal"`

Utiliza el valor de `padding`.

```tsx
<Layout padding={40} margin="normal" />
```

## `margin="estrecho"`

Aplica 36pt en todos los lados.

## `margin="ancho"`

Aplica 108pt en todos los lados.

## `margin="apa"`

Aplica 72pt (1 pulgada) en todos los lados.

Ideal para documentos académicos.

## `margin` como número

También puedes pasar un número directo en puntos (72 dpi = 1 pulgada):

```tsx
<Layout margin={50} />
```

# Fondo de Página

## Fondo de color

```tsx
<Layout backgroundColor="#f5f5f5">
```

## Imagen de fondo

```tsx
<Layout
  backgroundImage="/marca-agua.png"
  backgroundImageOpacity={0.2}
>
```

## Tamaño de página personalizado

Puedes definir un tamaño propio pasando un objeto `{ width, height }` en puntos:

```tsx
<Layout size={{ width: 400, height: 600 }} />
```

# Paginación Automática

```tsx
<Layout pagination={false}>
```

# NextPage

El componente **NextPage** permite insertar un salto de página manual dentro del documento. Utiliza internamente `<View break />` de `@react-pdf/renderer` para forzar el inicio de una nueva página.

## Uso

```tsx
<Layout>
  <H1>Primera Página</H1>
  <P>Contenido de la primera página...</P>
  
  <NextPage />
  
  <H1>Segunda Página</H1>
  <P>Contenido de la segunda página...</P>
</Layout>
```

## Casos de Uso

- Separar secciones importantes del documento
- Iniciar capítulos u apartados en nueva página
- Controlar manualmente la distribución de contenido
- Evitar que contenido importante se divida entre páginas

# Ejemplo Completo

```tsx
<Layout
  size="A4"
  orientation="portrait"
  margin="apa"
  backgroundColor="#ffffff"
  backgroundImage="/marca-agua.png"
  backgroundImageOpacity={0.15}
  footerLines={1}
  pagination
  paginationStyle={{ fontSize: 10, color: '#666' }}
  rule={false}
  dpi={300}
  id="pagina-principal"
  style={{ fontFamily: 'Helvetica' }}
  meta={{
    title: "Factura #1234",
    author: "Mi Empresa S.A.",
    subject: "Facturación Mensual",
    keywords: "factura pdf react",
    language: "es-ES",
    pdfVersion: "1.7",
    creationDate: new Date("2026-01-15"),
    modificationDate: new Date("2026-01-20"),
    userPassword: "cliente123",
    ownerPassword: "admin-super-seguro",
    permissions: {
      printing: "lowResolution",
      copying: false,
      modifying: false,
      contentAccessibility: true,
    },
    onRender: ({ blob }) => {
      console.log("PDF renderizado:", blob?.size, "bytes");
    },
  }}
>
  <H1>Título del Documento</H1>
  <P>Contenido del documento...</P>
</Layout>
```
