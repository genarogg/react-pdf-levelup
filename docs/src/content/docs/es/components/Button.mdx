## Button

Componente de botón estilizado con múltiples variantes de color y tamaños. Soporta enlaces (`href`) y estado deshabilitado.

El componente `Button` evita usar `borderWidth` real en la variante `outline` para prevenir el issue #395 de `@react-pdf/renderer` (stroke + borderRadius distorsiona las curvas). En su lugar, simula el borde mediante un anillo de relleno.

> ⚠️ **Limitación de la variante `outline`:** El workaround interno asume un fondo blanco (`#ffffff`) para simular el "interior transparente" del anillo. Si colocas un `Button` con `variant="outline"` sobre un fondo que **no es blanco**, el efecto visual de borde fallará. En ese caso, usa un `style` personalizado o coloca el botón únicamente sobre fondos blancos.

### Props

| Nombre       | Tipo                                                          | Default       | Descripción                                                                 |
| :----------- | :------------------------------------------------------------ | :------------ | :-------------------------------------------------------------------------- |
| `children`   | `React.ReactNode`                                             | `N/A`         | Texto o contenido interno del botón.                                        |
| `variant`    | `"primary" \| "secondary" \| "success" \| "danger" \| "outline"` | `"primary"`   | Variante de color del botón.                                                |
| `size`       | `"sm" \| "md" \| "lg"`                                        | `"md"`        | Tamaño predefinido (afecta padding y fontSize).                             |
| `disabled`   | `boolean`                                                     | `false`       | Desactiva el botón (colores apagados, sin enlace). Si `href` está presente junto a `disabled=true`, el enlace se ignora. |
| `href`       | `string`                                                      | `undefined`   | Si se provee y `disabled` es `false`, renderiza como enlace `Link`.         |
| `width`      | `number \| string`                                            | `undefined`   | Ancho explícito del botón. Acepta valores numéricos (puntos) o string (`"100%"`, `"200px"`). |
| `height`     | `number \| string`                                            | `undefined`   | Alto explícito del botón. Acepta valores numéricos (puntos) o string.       |
| `style`      | `any`                                                         | `undefined`   | Estilos adicionales para el contenedor exterior del botón. Se aplica al final del array de estilos, por lo que puede sobrescribir estilos base (backgroundColor, borderRadius, padding, width, height). |
| `textStyle`  | `any`                                                         | `undefined`   | Estilos adicionales para el texto interno del botón. Se aplica al final del array de estilos, por lo que puede sobrescribir fontSize, color, fontWeight. |

Además, hereda todas las propiedades de `View` de `@react-pdf/renderer` (ej: `margin`, `padding`, `flex`, `fixed`, `break`, `debug`), y cuando se usa con `href` y sin `disabled`, hereda también las propiedades de `Link` (ej: `onPress`).

### Tipos exportados

```ts
import { Button, type ButtonProps, type ButtonVariant, type ButtonSize } from '@react-pdf-levelup/core';
```

- `ButtonProps`: tipo completo de las props aceptadas por el componente.
- `ButtonVariant`: union type de variantes (`"primary" \| "secondary" \| "success" \| "danger" \| "outline"`).
- `ButtonSize`: union type de tamaños (`"sm" \| "md" \| "lg"`).

### Variantes

| Variante      | Fondo       | Texto       | Borde       |
| :------------ | :---------- | :---------- | :---------- |
| `primary`     | `#4338ca`   | `#ffffff`   | `#4338ca`   |
| `secondary`   | `#e6e8f0`   | `#1a1a2e`   | `#e6e8f0`   |
| `success`     | `#22C55E`   | `#ffffff`   | `#22C55E`   |
| `danger`      | `#EF4444`   | `#ffffff`   | `#EF4444`   |
| `outline`     | transparente| `#4338ca`   | `#4338ca`   |

### Tamaños

| Tamaño | Padding Vertical | Padding Horizontal | FontSize | BorderRadius |
| :----- | :--------------- | :----------------- | :------- | :----------- |
| `sm`   | 4                | 10                 | 9        | 4            |
| `md`   | 8                | 16                 | 11       | 6            |
| `lg`   | 12               | 22                 | 13       | 8            |

### Ejemplos

```tsx
import { Button, Center } from '@react-pdf-levelup/core';

// Botón primario mediano
<Button variant="primary">Aceptar</Button>

// Botón outline pequeño como enlace
<Button
  variant="outline"
  size="sm"
  href="https://example.com"
>
  Ver más
</Button>

// Botón danger grande deshabilitado
<Button variant="danger" size="lg" disabled>
  Eliminar (deshabilitado)
</Button>

// Botón success con ancho y alto fijos
<Button variant="success" width={200} height={40}>
  Guardar Cambios
</Button>

// Botón con ancho en porcentaje
<Button variant="secondary" width="100%">
  Botón de ancho completo
</Button>

// Botón con style personalizado (sobrescribe estilos base)
<Button variant="primary" style={{ marginTop: 10, marginBottom: 10, borderRadius: 12 }}>
  Con margen y borderRadius
</Button>

// Botón con textStyle personalizado
<Button variant="primary" textStyle={{ letterSpacing: 2, fontWeight: 'bold' }}>
  Texto estilizado
</Button>

// Botón con prop heredada de View (margin)
<Button variant="success" margin={5}>
  Con margen de 5pt
</Button>
```
