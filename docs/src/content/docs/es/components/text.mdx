## P, H1-H6

Componentes básicos de texto (párrafo y encabezados). Soportan todas las propiedades del componente `Text` de `@react-pdf/renderer`.

### Props

| Nombre | Tipo | Default | Descripción |
| :--- | :--- | :--- | :--- |
| `children` | `React.ReactNode` | `undefined` | Contenido interno (texto u otros componentes de texto). |
| `style` | `object` | `undefined` | Estilos adicionales para el texto. |
| `debug` | `boolean` | `false` | Activa el modo debug (bordes). |
| `fixed` | `boolean` | `false` | Indica si el elemento debe aparecer en todas las páginas. |
| `break` | `boolean` | `false` | Fuerza un salto de página antes del elemento. |

### Tamaños por defecto

Cada nivel de encabezado tiene un `fontSize` y `marginBottom` propios (todos en negrita por defecto):

| Componente | `fontSize` | `marginBottom` |
| :--------- | :--------- | :------------- |
| `H1`       | `24`       | `12`           |
| `H2`       | `20`       | `10`           |
| `H3`       | `18`       | `8`            |
| `H4`       | `16`       | `6`            |
| `H5`       | `14`       | `4`            |
| `H6`       | `12`       | `0`            |
| `P`        | (heredado) | `5`            |

### Ejemplo

```tsx
import { H1, H2, H3, H4, H5, H6, P } from '@react-pdf-levelup/core';

<H1>Título nivel 1</H1>
<H2>Título nivel 2</H2>
<H3>Título nivel 3</H3>
<H4>Título nivel 4</H4>
<H5>Título nivel 5</H5>
<H6>Título nivel 6</H6>
<P>Parrafo con texto normal.</P>
```

## Strong, Em, U, Small

Componentes de formato de texto en línea. Soportan todas las propiedades del componente `Text`.

- **Strong**: Texto en negrita.
- **Em**: Texto en cursiva (énfasis).
- **U**: Texto subrayado.
- **Small**: Texto más pequeño.

### Props

| Nombre | Tipo | Default | Descripción |
| :--- | :--- | :--- | :--- |
| `children` | `React.ReactNode` | `undefined` | Contenido interno (texto u otros componentes inline). |
| `style` | `object` | `undefined` | Estilos adicionales. |
| `color` | `string` | `undefined` | Color para aplicar al subrayado de `U`. |
| `debug` | `boolean` | `false` | Activa el modo debug (bordes). |
| `fixed` | `boolean` | `false` | Indica si el elemento debe aparecer en todas las páginas. |
| `break` | `boolean` | `false` | Fuerza un salto de página antes del elemento. |

### Ejemplo

```tsx
import { P, Strong, Em, U, Small } from '@react-pdf-levelup/core';

<P>
  <Strong>Negrita</Strong>, <Em>Cursiva</Em>, <U color="red">Subrayado rojo</U>, <Small>Pequeño</Small>
</P>
```

## A

### Props

| Nombre | Tipo | Default | Descripción |
| :--- | :--- | :--- | :--- |
| `children` | `React.ReactNode` | `undefined` | Texto o contenido visible del enlace. |
| `href` | `string` | `undefined` | URL del enlace (preferido). |
| `src` | `string` | `undefined` | URL del enlace (compatibilidad). Si `href` no se provee, se usa `src`. |
| `style` | `object` | `undefined` | Estilos adicionales. |
| `debug` | `boolean` | `false` | Activa el modo debug (bordes). |
| `fixed` | `boolean` | `false` | Indica si el elemento debe aparecer en todas las páginas. |
| `break` | `boolean` | `false` | Fuerza un salto de página antes del elemento. |

### Ejemplo

```tsx
import { A } from '@react-pdf-levelup/core';

<A href="https://example.com">Ir al sitio web</A>
```

## Div

Contenedor genérico para agrupar elementos. Soporta todas las propiedades del componente `View` de `@react-pdf/renderer`.

### Props

| Nombre | Tipo | Default | Descripción |
| :--- | :--- | :--- | :--- |
| `children` | `React.ReactNode` | `undefined` | Elementos hijos que se renderizan dentro del contenedor. |
| `style` | `object` | `undefined` | Estilos adicionales. |
| `debug` | `boolean` | `false` | Activa el modo debug (bordes). |
| `fixed` | `boolean` | `false` | Indica si el elemento debe aparecer en todas las páginas. |
| `break` | `boolean` | `false` | Fuerza un salto de página antes del elemento. |

### Ejemplo

```tsx
import { Div, P } from '@react-pdf-levelup/core';

<Div style={{ padding: 10, backgroundColor: '#f0f0f0' }}>
  <P>Contenido dentro de un Div</P>
</Div>
```
