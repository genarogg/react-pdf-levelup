# Graph

El componente **Graph** dibuja gráficos directamente con primitivas SVG nativas de `@react-pdf/renderer` (`Svg`, `Path`, `Rect`, `Line`, `Circle`, `G` + `Text` del namespace SVG). **No usa canvas ni Chart.js**. Como consecuencia, el texto de ejes, valores y etiquetas nace como nodo de texto PDF real, por lo que es **buscable y copiable** y no pierde calidad al hacer zoom.

> 💡 **Diferencia con `ChartJS`:** Si necesitas gráficos 100% compatibles con la API de Chart.js (incluyendo plugins, escalas avanzadas, leyendas custom, etc.), usa el plugin `ChartJS`, que rasteriza el gráfico a imagen. Si preferís texto vectorial y buscable, con una API reducida pero optimizada para PDF, usá `Graph`.

## Tipos auxiliares

Antes de las props, conviene conocer estas dos interfaces, que forman parte del contrato de entrada:

```ts
// Un punto individual del gráfico. `value` acepta `null` para expresar
// un hueco intencional (equivalente a spanGaps: false) en line/area.
interface GraphDataPoint {
  label: string;
  value: number | null;
  color?: string;  // color opcional para este punto (override por punto)
}

// Una serie (grupo de barras, una línea, un área, etc.).
// Pie/Donut usan solo 1 serie: cada `data` es una porción del círculo.
interface GraphSeries {
  name: string;           // nombre, usado en la leyenda para bar/line/area
  data: GraphDataPoint[]; // puntos
  color?: string;         // color opcional para TODA la serie
}
```

## Props

| Nombre         | Tipo                                                                       | Default     | Descripción                                                                                                                                                                                                                                      |
| :------------- | :------------------------------------------------------------------------- | :---------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `variant`      | `"bar" \| "horizontal-bar" \| "line" \| "area" \| "pie" \| "donut"`         | `N/A`       | **Requerido.** Tipo de gráfico a dibujar.                                                                                                                                                                                                       |
| `series`       | `GraphSeries[]`                                                             | `N/A`       | **Requerido.** Datos del gráfico (una o más series). Pie/Donut usan solo `series[0]`, cada `data` es una porción.                                                                                                                           |
| `width`        | `number`                                                                    | `500`       | Ancho total del `<Svg>` en unidades del viewBox. Debe ser un número (no acepta `%`).                                                                                                                                                          |
| `height`       | `number`                                                                    | `300`       | Alto total del `<Svg>` en unidades del viewBox. Debe ser un número.                                                                                                                                                                              |
| `title`        | `string`                                                                    | `undefined` | Título superior del gráfico. Renderizado como `Text` de bloque (no dentro del SVG).                                                                                                                                                              |
| `subtitle`     | `string`                                                                    | `undefined` | Subtítulo debajo del título. También es `Text` de bloque.                                                                                                                                                                                       |
| `colors`       | `string[]`                                                                  | `DEFAULT_COLORS` | Paleta de colores alternativa. Cada serie (o cada porción en pie/donut) toma `colors[index % colors.length]`. Si una serie o un punto declaran su propio `color`, ese tiene prioridad. Ver tabla abajo.                                |
| `showLegend`   | `boolean`                                                                   | `true`      | Mostrar/ocultar la fila de leyenda debajo del gráfico.                                                                                                                                                                                            |
| `showValues`   | `boolean`                                                                   | `false`     | Mostrar/ocultar el valor numérico sobre cada barra o al lado de cada porción de pie/donut.                                                                                                                                                       |
| `showDots`     | `boolean`                                                                   | `true`      | Solo para `line` y `area`. Dibuja un círculo en cada punto válido.                                                                                                                                                                               |
| `smooth`       | `boolean`                                                                   | `false`     | Solo para `line` y `area`. Suaviza la curva con splines de Catmull-Rom convertidos a Bézier (en vez de polilínea recta).                                                                                                                         |
| `yTickCount`   | `number`                                                                    | `5`         | Solo para bar, horizontal-bar, line, area. Cantidad aproximada de ticks en el eje de valores (el número final puede ajustarse para redondear "lindo").                                                                                            |
| `style`        | `any`                                                                       | `undefined` | Estilos adicionales para el `View` contenedor exterior (no el `<Svg>`). Puede usarse para `margin`, `padding`, `border`, `backgroundColor`, etc.                                                                                                  |

Además, como `style` cae sobre un `View`, heredan todas las props de `View` de `@react-pdf/renderer`.

## Límites y notas importantes

- **SVG Text y fuentes:** el `Text` dentro de `<Svg>` usa atributos de fuente SVG, no el `StyleSheet` de `@react-pdf/renderer`. Si el documento requiere una tipografía registrada vía `Font.register()` que también se vea dentro del gráfico, actualmente hay que inyectar ese `fontFamily` modificando el componente. El color y tamaño sí son configurables vía las constantes internas (`AXIS_FONT_SIZE`, `AXIS_TEXT_COLOR`) de `graph.tsx`.
- **`width` y `height` deben ser números:** el `viewBox` del `<Svg>` es exactamente ese ancho/alto. Si pasas un string (`"500"`) se coercirá a `NaN` por parte de `@react-pdf/renderer`.
- **Valores `null` como gaps (line/area):** en `line` y `area`, un punto con `value: null` corta el trazado (equivalente a `spanGaps: false`). Un punto aislado (solo 1 punto no-null entre gaps) se dibuja como un círculo, incluso con `showDots=false`, para que el dato no desaparezca.
- **Pie/Donut y valores negativos:** una porción no puede representar visualmente un valor negativo. Para el cálculo del ángulo se clampea a 0, pero si `showValues=true` el label continúa mostrando el valor real incluyendo el signo.
- **`rowSpan` no aplica:** el gráfico no usa tabla; no hay ninguna relación con `rowSpan`.
