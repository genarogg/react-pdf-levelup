## generatePDF

Asynchronous function to generate a PDF in base64 format from a React component.

### Signature

```typescript
generatePDF({ template, data }: { template: React.ElementType, data?: any }): Promise<string>
```

### Parameters

| Name       | Type                 | Description                                                  |
| :--------- | :------------------- | :----------------------------------------------------------- |
| `template` | `React.ElementType`  | The React component that represents the PDF document.        |
| `data`     | `any`                | Optional data to be passed as props to the template component. |

### Returns

Returns a promise that resolves to a `string` containing the base64 encoded PDF.

### Example

```tsx
import { generatePDF } from '@react-pdf-levelup/core';
import MyDocument from './MyDocument';

const handleGenerate = async () => {
  const base64 = await generatePDF({ 
    template: MyDocument, 
    data: { name: "John Doe" } 
  });
  console.log("Generated PDF:", base64);
};
```

## decodePDF

Takes an already generated PDF (base64, `Buffer`, or `Blob`) and processes it according to the environment: in the frontend it downloads it and/or opens it in a new tab; in the backend it saves it to disk.

### Signature

```typescript
decodePDF({ pdf, name, download, showBlob, saveSRC }: {
  pdf: string | Buffer | Blob;
  name: string;
  download?: boolean;  // frontend, default true
  showBlob?: boolean;  // frontend, default true
  saveSRC?: string;    // backend, required
}): Promise<void>
```

### Parameters

| Name       | Type                       | Description                                                        |
| :--------- | :------------------------- | :------------------------------------------------------------------ |
| `pdf`      | `string \| Buffer \| Blob` | The PDF to process, as base64, `Buffer`, or `Blob`.                 |
| `name`     | `string`                   | File name. `.pdf` is appended automatically if missing.             |
| `download` | `boolean`                  | Optional, frontend only. Whether to trigger the automatic download. Defaults to `true`. |
| `showBlob` | `boolean`                  | Optional, frontend only. Whether to open the PDF in a new tab. Defaults to `true`. |
| `saveSRC`  | `string`                   | Required in backend. Disk path where the PDF is saved. Without it, `decodePDF` throws in backend. |

### Example

```tsx
import { generatePDF, decodePDF } from '@react-pdf-levelup/core';
import MyDocument from './MyDocument';

const handleDownload = async () => {
  const base64 = await generatePDF({ template: MyDocument, data: { name: "John Doe" } });

  await decodePDF({
    pdf: base64,
    name: "document", // saved as "document.pdf"
  });
};
```
