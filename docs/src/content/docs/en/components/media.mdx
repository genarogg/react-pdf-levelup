## Img

Component for displaying images. Supports all properties of the `Image` component from `@react-pdf/renderer`. By default applies `width: "100%"` and `height: "auto"`, but can be overridden by `width` and `height` properties.

### Props

| Name    | Type     | Default    | Description                                                                       |
| :------ | :------- | :--------- | :-------------------------------------------------------------------------------- |
| `src`   | `string` | `undefined`| Image URL or path. |
| `style` | `object` | `{}` | Additional styles. |
| `width` | `string \| number` | `undefined` | Image width. |
| `height` | `string \| number` | `undefined` | Image height. |
| `debug` | `boolean`| `false`    | Enables debug mode (borders). |
| `fixed` | `boolean`| `false`    | Indicates if the element should appear on all pages. |
| `break` | `boolean`| `false`    | Forces a page break before the element. |

### Example

```tsx
import { Img } from '@react-pdf-levelup/core';

<Img src="https://picsum.photos/400/200" style={{ width: 200 }} />
```

## ImgBg

Background image with overlaid content. Places an image as an absolute background layer and renders `children` on top.

### Props

| Name             | Type                                                              | Default    | Description                                                                         |
| :--------------- | :---------------------------------------------------------------- | :--------- | :---------------------------------------------------------------------------------- |
| `src`            | `string`                                                          | `N/A`      | **Required.** Background image URL or path.                                         |
| `width`          | `number \| string`                                                | `"100%"`   | Width of the **background image** only. Does not affect the container size (see note below). |
| `height`         | `number \| string`                                                | `"100%"`   | Height of the **background image** only. Does not affect the container size (see note below). |
| `opacity`        | `number`                                                          | `0.2`      | Background image opacity (0 transparent — 1 opaque).                               |
| `objectFit`      | `"cover" \| "contain" \| "fill" \| "none" \| "scale-down"`       | `"cover"`  | How the image fits within the container.                                            |
| `objectPosition` | `"center" \| "top" \| "left" \| "right" \| "bottom"`             | `"center"` | Image position within the container.                                                |
| `fixed`          | `boolean`                                                         | `false`    | Fixes the image on all pages (passed directly to `Image.fixed`).                    |
| `children`       | `React.ReactNode`                                                 | `N/A`      | Content rendered on top of the background image.                                    |
| `style`          | `object`                                                          | `{}`       | Additional styles for the container.                                                |
| `debug`          | `boolean`                                                         | `false`    | Enables debug mode (borders).                                                       |
| `break`          | `boolean`                                                         | `false`    | Forces a page break before the element.                                             |

Additionally, it inherits all properties from `View` of `@react-pdf/renderer`.

> **Important:** the `ImgBg` container always takes `100%` width and `100%` height relative to its parent — this is fixed and does not change with the `width`/`height` props. Those two props only size the background image inside that container (useful together with `objectFit`/`objectPosition` to control how the image is cropped or scaled). If you need the **whole `ImgBg` block** to have a different size, use the `style` prop instead (e.g. `style={{ width: 300, height: 200 }}`), or let the container inherit its size from the surrounding layout/`children`.

### Example

```tsx
import { ImgBg, P, Center } from '@react-pdf-levelup/core';

<ImgBg
  src="https://picsum.photos/600/400"
  opacity={0.3}
  objectFit="cover"
  objectPosition="center"
>
  <Center>
    <P style={{ fontSize: 18, color: '#fff' }}>Text over background image</P>
  </Center>
</ImgBg>
```
