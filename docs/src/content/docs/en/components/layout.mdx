# Layout

The **Layout** component is the structural core of the PDF document.

Internally, it manages page configuration and wraps the content with the appropriate components from `@react-pdf/renderer` and automatically manages:

- Page size
- Orientation
- Predefined margin system
- Background color or image
- Automatic numbering
- Centimeter reference grid
- Debug mode

---

## Props

| Name                   | Type                                                                     | Default        | Description                                                                                                        |
|------------------------|--------------------------------------------------------------------------|----------------|--------------------------------------------------------------------------------------------------------------------|
| `size`                 | `PageSizeInput` (`PageSize \| { width: number; height: number }`) | `"A4"`         | Page size. Can be an ISO/American preset or a `{ width, height }` object in points (72 dpi). |
| `orientation`          | `"vertical" \| "horizontal" \| "portrait" \| "landscape" \| "h" \| "v"`      | `"vertical"`   | Page orientation. Internally transformed to `portrait` or `landscape`.                                             |
| `backgroundColor`      | `string`                                                                 | `"white"`      | Page background color.                                                                                             |
| `backgroundImage`      | `string`                                                                 | `undefined`    | URL of background image that covers the entire page.                                                               |
| `backgroundImageOpacity` | `number`                                                                 | `1`            | Opacity of the background image (0–1).                                                                             |
| `padding`              | `number`                                                                 | `30`           | Base padding when `margin="normal"`.                                                                             |
| `margin`               | `MarginInput` (`"apa" \| "normal" \| "estrecho" \| "ancho" \| number`) | `"normal"`     | Margin system. Accepts a preset or a number in points for all 4 sides. |
| `style`                | `object`                                                                 | `{}`           | Additional styles for the page.                                   |
| `footerLines`                | `number`                                                                 | `1` | Number of footerLines reserved at the bottom (used by the pagination container to avoid overlapping content).                                                                           |
| `pagination`           | `boolean`                                                                | `true`         | Shows automatic page numbering.                                                                                    |
| `paginationStyle`      | `any`                                                                    | `undefined`    | Additional styles for the pagination `<Text>` inside the footer container (e.g. `{ fontSize: 10, color: '#999' }`). |
| `rule`                 | `boolean`                                                                | `false`        | Shows centimeter reference grid.                                                                                   |
| `debug`                | `boolean`                                                                | `false`        | Activates `@react-pdf/renderer` debug mode.                                                                        |
| `dpi`                | `number`                                                                | `undefined`        | Page DPI resolution (passed directly to `<Page dpi>` from `@react-pdf/renderer`).                                                                        |
| `id`                | `string`                                                                | `undefined`        | HTML/CSS ID of the underlying `<Page>` element.                                                                        |
| `meta`                 | `DocumentMeta`                                                           | `{}`           | Document metadata (title, author, keywords, passwords, permissions, etc.). |

# Document Metadata (`meta`)

The `meta` prop allows you to configure standard PDF file metadata, which is visible in the document properties of any PDF viewer.

## `meta` Properties

| Property | Type | Description |
|----------|------|-------------|
| `title` | `string` | Document title. |
| `author` | `string` | Document author. |
| `subject` | `string` | Document subject. |
| `keywords` | `string` | Keywords (space-separated). |
| `creator` | `string` | Application that created the document (Default: `react-pdf-levelup`). |
| `producer` | `string` | Application that produced the PDF (Default: `react-pdf-levelup`). |
| `pdfVersion` | `"1.3" \| "1.4" \| "1.5" \| "1.6" \| "1.7" \| "1.7ext3"` | PDF standard version. |
| `language` | `string` | Document language (e.g., `en-US`). |
| `pageMode` | `string` | How the document should be displayed when opened (`useNone`, `useOutlines`, `useThumbs`, `fullScreen`). |
| `pageLayout` | `string` | The page layout to use (`singlePage`, `oneColumn`, `twoColumnLeft`, `twoColumnRight`). |
| `creationDate` | `Date` | Document creation date. |
| `modificationDate` | `Date` | Document last modification date. |
| `ownerPassword` | `string` | Owner password (to protect the PDF). |
| `userPassword` | `string` | User password (to open the PDF). |
| `permissions` | `DocumentPermissions` | Granular document permissions (see table below). |
| `onRender` | `(props: { blob?: Blob }) => any` | Callback executed when the document finishes rendering, receives the PDF `Blob`. |

### Permissions (`DocumentPermissions`)

| Property | Type | Description |
|----------|------|-------------|
| `printing` | `"lowResolution" \| "highResolution"` | Allows printing the document in low or high resolution. If omitted, printing is not allowed. |
| `modifying` | `boolean` | Allows modifying the document content. |
| `copying` | `boolean` | Allows copying/extracting text and images. |
| `annotating` | `boolean` | Allows adding or modifying annotations. |
| `fillingForms` | `boolean` | Allows filling form fields. |
| `contentAccessibility` | `boolean` | Allows extracting content for accessibility (screen readers). |
| `documentAssembly` | `boolean` | Allows document assembly (insert, rotate, or delete pages). |

## Usage Example

```tsx
<Layout
  meta={{
    title: "Invoice #1234",
    author: "My Company Inc.",
    subject: "Monthly Billing",
    keywords: "invoice pdf react",
    language: "en-US"
  }}
>
  {/* Content */}
</Layout>
```

# Margin System

The Layout includes a predefined margin system to facilitate layout.

## `margin="normal"`

Uses the `padding` value.

```tsx
<Layout padding={40} margin="normal" />
```

## `margin="estrecho"`

Applies 36pt on all sides.

## `margin="ancho"`

Applies 108pt on all sides.

## `margin="apa"`

Applies 72pt (1 inch) on all sides.

Ideal for academic documents.

## `margin` as a number

You can also pass a direct number in points (72 dpi = 1 inch):

```tsx
<Layout margin={50} />
```

# Page Background

## Color Background

```tsx
<Layout backgroundColor="#f5f5f5">
```

## Background Image

```tsx
<Layout
  backgroundImage="/marca-agua.png"
  backgroundImageOpacity={0.2}
>
```

## Custom Page Size

You can define a custom size by passing a `{ width, height }` object in points:

```tsx
<Layout size={{ width: 400, height: 600 }} />
```

# Automatic Pagination

```tsx
<Layout pagination={false}>
```

# NextPage

The **NextPage** component allows you to insert a manual page break within the document. It internally uses `<View break />` from `@react-pdf/renderer` to force the start of a new page.

## Usage

```tsx
<Layout>
  <H1>First Page</H1>
  <P>Content of the first page...</P>
  
  <NextPage />
  
  <H1>Second Page</H1>
  <P>Content of the second page...</P>
</Layout>
```

## Use Cases

- Separate important sections of the document
- Start chapters or sections on a new page
- Manually control content distribution
- Prevent important content from splitting across pages

# Complete Example

```tsx
<Layout
  size="A4"
  orientation="portrait"
  margin="apa"
  backgroundColor="#ffffff"
  backgroundImage="/marca-agua.png"
  backgroundImageOpacity={0.15}
  footerLines={1}
  pagination
  paginationStyle={{ fontSize: 10, color: '#666' }}
  rule={false}
  dpi={300}
  id="main-page"
  style={{ fontFamily: 'Helvetica' }}
  meta={{
    title: "Invoice #1234",
    author: "My Company Inc.",
    subject: "Monthly Billing",
    keywords: "invoice pdf react",
    language: "en-US",
    pdfVersion: "1.7",
    creationDate: new Date("2026-01-15"),
    modificationDate: new Date("2026-01-20"),
    userPassword: "customer123",
    ownerPassword: "super-secure-admin",
    permissions: {
      printing: "lowResolution",
      copying: false,
      modifying: false,
      contentAccessibility: true,
    },
    onRender: ({ blob }) => {
      console.log("PDF rendered:", blob?.size, "bytes");
    },
  }}
>
  <H1>Document Title</H1>
  <P>Document content...</P>
</Layout>
```
