# Table

The `Table`, `Thead`, `Tbody`, `Tr`, `Th`, and `Td` components provide a complete table system for PDF documents, including preset styles, zebra rows, headers, rounded borders support, and manual page splitting.

---

## Table

Main container. Injects a shared context (`TableContext`) with colors, sizes and grid mode, and controls rendering of borders/rounded corners as well as manual pagination through `rowsPerPage`.

### Props

| Name                 | Type                                                                       | Default     | Description                                                                                                                                                                                                                               |
| :------------------- | :------------------------------------------------------------------------- | :---------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `children`           | `React.ReactNode`                                                          | `N/A`       | Table content. Recommended structure: one `Thead` + one `Tbody` wrapping `Tr`s.                                                                                                                                                           |
| `style`              | `any`                                                                      | `{}`        | Extra styles for the outer container (passed to a `View`). **Note:** if `style` includes an explicit `borderRadius`, the border-radius bug workaround is automatically enabled (issue #395 of `@react-pdf/renderer`).                    |
| `cellHeight`         | `number`                                                                   | `22`        | Default minimum height (`minHeight`) for cells that don't declare their own `height`.                                                                                                                                                     |
| `borderColor`        | `string`                                                                   | `"#000"`    | Outer border and internal grid color. Also used as fallback when the user doesn't provide a border color inside `style`.                                                                                                                  |
| `textColor`          | `string`                                                                   | `"#000"`    | Default text color for the whole table (can be overridden by `Thead`, `Tbody` or each individual cell).                                                                                                                                   |
| `headerBackground`   | `string`                                                                   | `"#ccc"`    | Background color of the header container (`Thead`).                                                                                                                                                                                       |
| `zebra`              | `boolean`                                                                  | `true`      | Enables zebra pattern (odd rows with alternate background).                                                                                                                                                                               |
| `zebraColor`         | `string`                                                                   | `"#eeeeee"` | Background color used for odd rows when `zebra: true`. Only affects `Td` — `Th` never gets zebra.                                                                                                                                        |
| `grid`               | `"grid" \| "modern" \| "not-grid"`                                         | `"grid"`    | Internal grid style: **grid** → full borders, **modern** → only bottom borders between rows, **not-grid** → no internal borders (compensated with padding so cell size stays consistent).                                                 |
| `borderRadiusMethod` | `"view" \| "svg"`                                                          | `"svg"`    | Which implementation to use for the `borderRadius` bug workaround. `"view"` simulates the border with an outer filler `View`; `"svg"` draws the outline with an overlay SVG stroke (allows transparent interior). ⚠️ The actual default in code (`Table.tsx`) is `"svg"` — other internal modules (`TableContext`, `border-radius-fix.ts`) document `"view"` as the default, so pass the value explicitly if your render doesn't match expectations. |
| `rowsPerPage`        | `Array<{ nRow: number; break?: boolean }>`                                 | `undefined` | If provided, **splits `Tbody` into several independent tables**, one per row "chunk", repeating `Thead` on each chunk with its own borders/radii. See the dedicated section below.                                                          |
| `[key: string]`      | `any`                                                                      | —           | Any other `View` prop from `@react-pdf/renderer`: `wrap`, `break`, `id`, `fixed`, `debug`, etc.                                                                                                                                            |

### Grid modes (`grid`)

| Mode         | Right border between columns | Bottom border between rows | Outer border    |
| :----------- | :--------------------------- | :------------------------- | :-------------- |
| `"grid"`     | ✅ (all but last)            | ✅ (all but last row)      | ✅ (by `Table`)  |
| `"modern"`   | ❌                           | ✅ (all but last row)      | ✅ (by `Table`)  |
| `"not-grid"` | ❌ (padding compensated)     | ❌ (padding compensated)   | ✅ (by `Table`)  |

### `borderRadius` workaround (bug #395 of `@react-pdf/renderer`)

`@react-pdf/renderer` distorts corner curves when the same `View` combines real `borderWidth` (stroke) + `borderRadius`. To prevent this, when `style` carries an explicit `borderRadius`, `Table` **does not use a real border** on the outer container. Instead it applies one of these two methods, selectable via `borderRadiusMethod`:

- **`"view"`**: builds a "sandwich" — an outer `View` with `backgroundColor: borderColor` + `padding: borderWidth` + `borderRadius`, and the real content inside with its own `backgroundColor`. Simple and robust. **Limitation:** the table interior ALWAYS has some `backgroundColor` (forced by the inner layer) — it cannot be 100% transparent.

- **`"svg"`** (default): leaves the content "hollow" and draws **on top of it**, overlaid, a contour made of 4 SVG corner arcs + 4 straight `View` segments joining the corners. **Advantage:** the table interior remains transparent if the user specified no `backgroundColor` in `style`, and it does not suffer the practical ~12 radius limit of the "view" method. **Limitation:** uses 8 pieces, more complex syntax internally.

Fix activation is **automatic via `borderRadius`**, not via `borderRadiusMethod`. If `style` has no `borderRadius`, neither method is applied — the table uses plain `borderWidth` as usual.

> ⚠️ Known limitation ("view" method): with `borderRadius` above ~12, the two nested Views approximation may show a small visual misalignment at the corners. For large radii prefer `borderRadiusMethod: "svg"`.

### Manual page splitting (`rowsPerPage`)

By default `@react-pdf/renderer` splits tables "wherever it fits", without cleanly closing/reopening borders or repeating the header. To control this precisely, `Table` provides `rowsPerPage`.

**How to use it:** pass an array of entries, one per chunk, where each entry defines:

- `nRow`: **how many rows of this table fit** on that page (not cumulative).
- `break` (optional, default `false`): whether a page break should be forced before rendering **that** chunk.

If `Tbody` has more rows than your entries cover, the remainder keeps being split **repeating the last entry** (same `nRow` and same `break`) until exhausted.

Important rules:
- While `rowsPerPage` triggers a real split, the top-level `break` prop on `Table` is ignored — each chunk controls its own page break through its internal `break`.
- If structure is not `Thead + Tbody` (e.g., if `children` lacks those components), `rowsPerPage` silently deactivates and falls back to normal behaviour.
- Each chunk renders its own `Thead` and its own full border/radius — as if you had written N separate `<Table>`s by hand.

```tsx
// Knowing that ~5 rows fit on my page, and I want an explicit break before
// the 2nd chunk (but not anymore for the 3rd and beyond — they repeat the last).
<Table
  cellHeight={22}
  borderColor="#222"
  style={{ borderRadius: 6 }}
  rowsPerPage={[
    { nRow: 5, break: false },
    { nRow: 5, break: true  },  // forces page break before this chunk
    // 3rd, 4th, ... repeat the last: nRow=5, break=true
  ]}

  </Thead>
  <Tbody>
    {/* 27 rows → 5 + 5 + 5 + 5 + 5 + 2, with break before 2nd..6th */}
    {Array.from({ length: 27 }).map((_, i) => (
      <Tr key={i}><Td>{i + 1}</Td><Td>Item {i + 1}</Td></Tr>
    ))}
  </Tbody>
</Table>
```

## Thead

Header section. Renders a `View` with `backgroundColor: headerBackground` from the context, applies `borderTopLeftRadius` / `borderTopRightRadius` when the border-radius fix is active, and overrides the shared context's `textAlign`, `borderColor` and `textColor` for all descendants.

### Props

| Name          | Type                               | Default          | Description                                                               |
| :------------ | :--------------------------------- | :--------------- | :------------------------------------------------------------------------ |
| `children`    | `React.ReactNode`                  | `N/A`            | Header rows (generally one or more `Tr`s with `Th` inside).              |
| `style`       | `any`                              | `{}`             | Additional styles for the header container.                               |
| `textAlign`   | `"left" \| "center" \| "right"`    | `"left"`         | Default alignment for header cells (overrides `Table`).                   |
| `borderColor` | `string`                           | `(from context)` | Overrides `borderColor` inherited from `Table` for this `Thead`.          |
| `textColor`   | `string`                           | `(from context)` | Overrides `textColor` inherited from `Table` for this `Thead`.            |
| `[key: string]` | `any`                            | —                | Any other `View` prop (wrap, break, id, fixed, debug, etc.).              |

### Example

```tsx
<Thead textAlign="center" textColor="#fff" borderColor="#4338ca">
  <Tr>
    <Th>Name</Th>
    <Th>Age</Th>
  </Tr>
</Thead>
```

## Tbody

Body section. For each `Tr` it contains, it injects via `cloneElement`:

- `isLastRow: idx === count - 1` (used by `Cell` to round bottom corners and/or remove the last row bottom border).
- `isOdd: idx % 2 === 1` (used by `Td` to apply zebra).
- Any extra `[key: string]` prop you pass to `Tbody` is propagated as-is to each `Tr`.

### Props

| Name           | Type              | Default          | Description                                                                  |
| :------------- | :---------------- | :--------------- | :--------------------------------------------------------------------------- |
| `children`     | `React.ReactNode` | `N/A`            | Body rows (`Tr` components with `Td` inside).                               |
| `borderColor`  | `string`          | `(from context)` | Overrides `borderColor` of the context for this `Tbody`.                    |
| `textColor`    | `string`          | `(from context)` | Overrides `textColor` of the context for this `Tbody`.                      |
| `[key: string]`| `any`             | —                | Any other prop is propagated as-is to each inner `Tr`.                      |

## Tr

Table row (works both inside `Thead` and `Tbody`). Its main responsibility is **computing the real width of each cell**, since `@react-pdf/renderer` has no native table engine (everything is flexbox):

- Sums the "column units" of the row: each cell contributes `colSpan` (default `1`) units.
- Per cell: if the cell already brings its own manual `width`, it's respected. Otherwise a percentage width is computed: `100% * colSpan / totalUnits`.
- Additionally, it passes to each cell via `cloneElement`: the resolved `width`, `isFirst`, `isLast`, and forwards `isLastRow` / `isOdd` received from `Tbody`.

### Props

| Name            | Type              | Default     | Description                                                                      |
| :-------------- | :---------------- | :---------- | :------------------------------------------------------------------------------- |
| `children`      | `React.ReactNode` | `N/A`       | Row cells (`Th` or `Td`).                                                        |
| `style`         | `any`             | `{}`        | Additional styles for the row `View`.                                            |
| `isLastRow`     | `boolean`         | `false`     | Whether this is the last row of `Tbody`. Injected by `Tbody`, but you can set it manually if you use `Tr` standalone. |
| `isOdd`         | `boolean`         | `false`     | Whether the row is odd (for zebra). Injected by `Tbody`.                         |
| `[key: string]` | `any`             | —           | Any other `View` prop.                                                           |

## Th and Td

`Th` (header cell) and `Td` (data cell) are thin wrappers over the same internal `Cell` component. They only differ in:

1. **`Th`** uses `styles.th` (`fontWeight: bold`) and **never** applies zebra nor rounds bottom corners.
2. **`Td`** uses `styles.td`, applies zebra when `zebra && isOdd`, and rounds bottom corners of the last row when `borderRadius` is present.

Both share the following public API:

### Common props for Th and Td

| Name            | Type                               | Default          | Description                                                                                                                                                                                                                                                            |
| :-------------- | :--------------------------------- | :--------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `children`      | `React.ReactNode`                  | `undefined`      | Cell content. Can be string, number, or components.                                                                                                                                                                                                                    |
| `style`         | `any`                              | `{}`             | Additional styles for the cell container `View`. Applied last, after base styles.                                                                                                                                                                                      |
| `width`         | `string \| number`                 | `undefined`      | **Explicit width** of the cell. If not provided, `Tr` automatically computes the proportional width based on `colSpan`. Valid values: `"100%"`, `"120px"`, `120` (number = points). This value **takes priority** over automatic calculation — a cell with `width` is excluded from `totalUnits`. |
| `height`        | `string \| number`                 | `(cellHeight)`   | **Minimum height** of the cell (applied as `minHeight` on the `View`). If not provided, uses `cellHeight` from `TableContext` (default 22).                                                                                                                            |
| `colSpan`       | `number`                           | `1`              | How many columns the cell "spans", in logical units. Only affects **width** (horizontal, within the same row) — there's no real cell merging, just a proportionally wider cell. **`rowSpan` does not exist / is not supported.**                                        |
| `textAlign`     | `"left" \| "center" \| "right"`    | `(from context)` | Text alignment. Precedence: explicit value on cell → value from `Thead`/context → default `"left"`.                                                                                                                                                                   |
| `text`          | `boolean`                          | `true`           | **Critical.** If `true` (default), content is wrapped in a `<Text>` before render (correct for strings/numbers). **Set to `false` when `children` is a `View`-based component** (e.g. a `Badge`), because `Text` cannot contain `View` in `@react-pdf/renderer`.          |
| `isFirst`       | `boolean`                          | `false`          | Injected by `Tr`. Marks the first cell in a row (used to drop `borderRightWidth` and for `borderBottomLeftRadius` on the last row). Can be overridden manually if using `Td`/`Th` outside a `Tr`.                                                                       |
| `isLast`        | `boolean`                          | `false`          | Injected by `Tr`. Analogous to the above.                                                                                                                                                                                                                              |
| `isLastRow`     | `boolean`                          | `false`          | Injected by `Tbody` → `Tr`. Used to round bottom corners and drop `borderBottomWidth` in grid mode.                                                                                                                                                                   |
| `isOdd`         | `boolean`                          | `false`          | Injected by `Tbody` → `Tr`. Marks odd rows for zebra in `Td`.                                                                                                                                                                                                          |
| `[key: string]` | `any`                              | —                | Any other `View` prop (or `Text` prop if `text=true`): `wrap`, `break`, `id`, `fixed`, `debug`, etc.                                                                                                                                                                  |

### Important notes

- **rowSpan not supported:** the table is built with pure `View` (flexbox) from `@react-pdf/renderer`, and each `Tr` is a sibling independent of the previous one, with no visibility of "occupied" columns across rows. There is no clean way to do vertical merging without breaking PDF page-break flow. If you need that visual effect, use a manually positioned `View` outside the `Tr`/`Td` scheme.
- **text=false:** if your cell contains a `View`-based component (e.g. a styled badge with an inner round `View`), **always** pass `text={false}`. Otherwise `@react-pdf/renderer` will fail during render because it tries to nest a `View` inside a `Text`.
- **colSpan is resolved in Tr:** `Cell` receives `colSpan` only to exclude it from the props passed to the native `View`; the actual width calculation happens in `Tr`. It does nothing if `Td` has an explicit `width`.
