## Left, Right, Center

Utility components for aligning content horizontally and optionally vertically. All three (`Left`, `Right`, `Center`) share the same API. They only differ in their default horizontal alignment.

- **Left**: Aligns content to the left (`alignItems: "flex-start"`).
- **Right**: Aligns content to the right (`alignItems: "flex-end"`).
- **Center**: Aligns content horizontally centered (`alignItems: "center"`).

Internally they are wrappers on top of `View` from `@react-pdf/renderer`.

### Props (shared by Left, Right and Center)

| Name       | Type              | Default     | Description                                                                                                                   |
| :--------- | :---------------- | :---------- | :---------------------------------------------------------------------------------------------------------------------------- |
| `children` | `React.ReactNode` | `N/A`       | Content to align.                                                                                                             |
| `vertical` | `boolean`         | `false`     | If `true`, also centers vertically (`justifyContent: "center"`). Useful for content with a known height.                     |
| `style`    | `any`             | `undefined` | Additional styles (merged last).                                                                                              |

Additionally, they inherit all properties from `View` of `@react-pdf/renderer` (`debug`, `fixed`, `break`, etc.).

### Examples

```tsx
import { Left, Right, Center, P, Div } from '@react-pdf-levelup/core';

// Simple horizontal alignment
<Left>
  <P>Text to the left</P>
</Left>

<Right>
  <P>Text to the right</P>
</Right>

<Center>
  <P>Centered text</P>
</Center>

// Horizontal alignment + vertical center in a tall container
<Div style={{ height: 120, backgroundColor: '#f0f0f0' }}>
  <Center vertical>
    <P>Horizontally and vertically centered</P>
  </Center>
</Div>
```
