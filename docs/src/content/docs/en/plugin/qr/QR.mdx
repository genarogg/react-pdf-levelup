# QR

The `QR` component allows generating simple QR codes with the option to embed a logo in the center. It is useful for quickly and easily adding encoded information to your PDF documents.

It uses its own generation engine (`generateQRAsBase64`, based on the `qrcode` library), independent from the `QRstyle` engine (based on `qr-code-styling`). If you need advanced customization of corners, dots, or a center image with more control, use [QRstyle](/docs/en/plugin/qr/QRstyle) instead.

### Props

| Name                   | Type                               | Default                      | Description                                                     |
| :--------------------- | :--------------------------------- | :--------------------------- | :-------------------------------------------------------------- |
| `url`                  | `string`                           | `""`                         | The text or URL to be encoded in the QR code.                   |
| `size`                 | `number`                           | `150`                        | Size of the QR code in pixels (width and height).               |
| `style`                | `any`                              | `{}`                         | Additional styles for the QR code container.                    |
| `colorDark`            | `string`                           | `"#000000"`                  | Color of the dark modules (dots) of the QR code.                |
| `colorLight`           | `string`                           | `"#ffffff"`                  | Background color of the QR code.                                |
| `margin`               | `number`                           | `0`                          | Margin around the QR code in pixels.                            |
| `logo`                 | `string`                           | `undefined`                  | URL of the logo image to embed in the center of the QR. If omitted, no logo is embedded. |
| `logoWidth`            | `number`                           | `size * 0.2`                 | Width of the logo in pixels.                                    |
| `logoHeight`           | `number`                           | `size * 0.2`                 | Height of the logo in pixels.                                   |
| `errorCorrectionLevel` | `"L" \| "M" \| "Q" \| "H"`         | `"M"`                        | Error correction level of the QR code. Allows data recovery if the code is damaged. If embedding a logo, `"H"` is recommended for better tolerance against occlusion. |
| `debug` | `boolean` | `false` | Enables debug mode (borders). |
| `fixed` | `boolean` | `false` | Indicates if the element should appear on all pages. |
| `break` | `boolean` | `false` | Forces a page break before the element. |

> **Note on `logo`:** when `logo` is passed, the component first generates the base QR and then embeds the logo image on a canvas (via `addLogoToQR`), clipping a white background around the logo to keep contrast. In Node (SSR / backend generation) this requires the `canvas` package to be available in the environment; in the browser it uses the native `canvas`. If `canvas` is not available in Node, the QR is still generated, just without the logo.

### Example

```tsx
import { QR } from '@react-pdf-levelup/core';

function MyQRCode() {
  return (
    <QR
      url="https://react-pdf-levelup.com"
      size={200}
      colorDark="#1a202c"
      colorLight="#f7fafc"
      margin={5}
      logo="https://picsum.photos/id/237/200/200"
      logoWidth={40}
      logoHeight={40}
      errorCorrectionLevel="H"
    />
  );
}
```

### QR without a logo

```tsx
<QR url="https://react-pdf-levelup.com" size={150} />
```
