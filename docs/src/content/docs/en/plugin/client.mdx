# Client Plugin (`@react-pdf-levelup/client`)

> ℹ️ **Confirmed against the source code:** `@react-pdf-levelup/client` is a real package that re-exports `generatePDF`, `decodePDF`, and `getFont` from the same source as `@react-pdf-levelup/core` (`frontend/src/functions`). It's a subset of `core` — it doesn't include the PDF components (`Layout`, `Table`, `Button`, etc.), nor the worker functions (those live in `@react-pdf-levelup/server`). `printBase64Pdf` does **not** appear in the `client` source code reviewed for this audit — if your installation exposes it, confirm against your version's actual `package.json`/exports.

The `@react-pdf-levelup/client` plugin exposes the PDF generation and handling functions without pulling in `core`'s components — useful when you only need `generatePDF`/`decodePDF`/`getFont` on the client.

## Exported Functions

### `generatePDF`

Generates a PDF document from a React component, automatically detecting whether it's running in the backend or frontend. It's the same function documented under `@react-pdf-levelup/core`.

- [View detailed documentation for `generatePDF`](/docs/en/guides/functions/generate-pdf/single)

### `decodePDF`

Takes an already generated PDF (base64, `Buffer`, or `Blob`) and processes it according to the environment: in the frontend it downloads it and/or opens it in a new tab; in the backend it saves it to disk.

- [View detailed documentation for `decodePDF`](/docs/en/guides/functions/generate-pdf/single#decodepdf)

### `getFont`

Resolves a font file's path so it can be registered with `Font.register`, automatically adjusting for the environment (URL, absolute path, browser, or Node).

- [View detailed documentation for `getFont`](/docs/en/guides/functions/fonts)

### `printBase64Pdf` <Badge text="unconfirmed" variant="caution" />

A function mentioned in earlier versions of this documentation for printing a PDF from a Base64 string (creating a hidden iframe and triggering the browser's print dialog). It doesn't appear in the `client` source code reviewed for this audit — confirm whether it exists in your installation before using it.

- **Parameters**: `base64Data` (string) - A Base64 encoded PDF string
- **Returns**: void

## Usage

```tsx
import { generatePDF, decodePDF } from '@react-pdf-levelup/client';
import { Layout, P } from '@react-pdf-levelup/core';

const myTemplate = ({ data }) => {
  return (
    <Layout>
      <P>Hello, {data.name}</P>
    </Layout>
  );
};

async function createAndDownloadPdf() {
  const data = { name: 'World' };
  const base64Pdf = await generatePDF({ template: myTemplate, data });
  await decodePDF({ pdf: base64Pdf, name: 'my-document' });
}

createAndDownloadPdf();
```
